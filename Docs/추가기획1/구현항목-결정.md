## 1. 확정 결정 (2026-09-04)

### 1-1. 방어선 — 3단 개편

| 단 | 맵 | 시설 | HP | 파괴 시 |
|---|---|---|---|---|
| 1 | 사냥터2 | **포탑 1기** (공격 있음) | 800 | 파괴 + 미니언 레인 끝 도달 → 전선 사냥터1 |
| 2 | 사냥터1 | **억제기** (공격 없음) | 1,200 | 넥서스 노출 + 미니언 강화 (+ 미니언 경험치 상승 `SuppressorExpMul` 유지) |
| 3 | 마을 | **넥서스** (마을 **하단 미니언 길 위**) | 2,000 | 즉시 탈락 · 재건 불가 |

- 미니언은 사냥터2 → 사냥터1 → 마을 **하단 전용 1자 길**만 걷는다.
- 재건: 포탑 빅토리아 주화 30 (억제기 생존 시만) · 억제기 50. **전선은 되돌아가지 않는다** (로드맵 미정 #9 → 불허 확정). 재건 포탑은 현재 전선에 남은 미니언만 막는다.
- 억제기 재건 시 넥서스 노출·미니언 강화 해제. `SuppressorDownEvent` 는 "파괴 사이클당 1회".
- **맵당 시설 1개.** 추가기획1 의 "포탑×2" 는 사용자 확정으로 **포탑 1개**로 변경 (2026-09-04).
- 내부 식별자 `CORE` / `VillageCore*` 유지, **"넥서스"는 표시명**. `TowerStage` 는 **3값**(`TOWER` · `SUPPRESSOR` · `CORE`; `TOWER1`/`TOWER2` 폐기), `LaneStage` 는 전선 맵 기준 3값(1=사냥터2 · 2=사냥터1 · 3=마을). `TowerConfig` 행도 3 Stage × Level.

### 1-2. 수비 몬스터(펫)

- 배치: 포탑·억제기·넥서스 라인에만, **마을당 10칸 (전 직업 동일)**. 발록전 동행 불가. 사망 = 영구 소실.
- **"칸" = 묶음 단위 인구 상한.** 1묶음 ≈ 10마리(몬스터별 묶음 크기는 데이터). 예: 뿔버섯 15마리 = 1묶음 = 1칸, 20마리 = 2칸. 10칸 = 최대 10묶음.
- **AI (확정)**: 유저 배치 없음 → 모집 즉시 **현재 최전방 시설(포탑 → 억제기 → 넥서스) 앞으로 자동 집결**(맵 넘어감). 시설이 파괴되면 다음 시설 앞으로, 재건되면 다시 전진. 추격 없음 — **하단 길 위를 직진**하며 마주치는 적과 교전, 위 발판으로 올라가지 않음. 타겟 = **최근접 적**(현행 `FactionLogic.IsEnemy`). 구현 기반: `Faction/FactionAI.mlua`(전진형) + 집결지 도착 시 `AdvanceDir=0`.
- 모집: **몬스터별 재화 8개** (지역당 3종 = 15종, 드랍률 기본 20%). 모집 결과 = 그 사냥 몹의 수비 버전 (모델 재사용).
- **모집 창 상단에 미니 방어선 프리뷰** (2026-09-04): 배치 UI 는 없지만 **현재 최전방 시설 그림(포탑 → 없으면 억제기 → 없으면 넥서스) + 10묶음 아이콘 + "N묶음 · N마리 · N/10칸"** 을 보여준다. 시설 아이콘은 임시 RUID(WO-011 §4-1b), 나중에 교체.
- 훈련: **종류(병과) 단위** Lv1~5, 꿈의 조각 3/5/10/15 즉시 소모, 스탯 배율 1.0/1.5/2.2/3.3/5.0. 45초·과부하 배수 폐기. 직업별 상한 차이 없음.
