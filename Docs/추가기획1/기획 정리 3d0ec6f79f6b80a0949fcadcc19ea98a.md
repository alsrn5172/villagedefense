## 2. 마을 방어 구조 (넥서스 3단 구조 확정)

기존 터렛/벙커/포탑 구조를 **포탑 → 억제기 → 넥서스** 3단으로 교체함.

### 2-1. 구조

```
미니언 진입로 (여섯갈래길 → 사냥터2 → 사냥터1 → 마을 · 각 맵 하단 전용 1자 길)
     ↓
 [포탑 ×1]  ← 1차 방어선 · 사냥터2
     ↓
 [억제기]   ← 2차 방어선 · 사냥터1
     ↓
 [넥서스]   ← 마을 하단 길 위 · 파괴되면 즉시 탈락
```

### 2-2. 시설 스펙

| 시설 | 개수 | HP | 공격 | 파괴 시 |
| --- | --- | --- | --- | --- |
| **포탑** | 1개 (사냥터2) | 800 | 있음 | 파괴 + 미니언 레인 끝 도달 → 전선 사냥터1 (억제기 노출) |
| **억제기** | 1개 (사냥터1) | 1,200 | 없음 | 넥서스 노출 + **미니언 강화** (+ 미니언 경험치 소폭 상승) |
| **넥서스** | 1개 (마을 하단 길) | 2,000 | 없음 | **즉시 탈락** |

맵당 시설 1개. 전선은 포탑 → 억제기 → 넥서스 순으로만 밀리고, **되돌아가지 않는다.**

### 2-3. 펫(수비 몬스터) 배치

| 항목 | 규칙 |
| --- | --- |
| 배치 위치 | **포탑·억제기·넥서스 라인에만** |
| 배치 칸 | **10칸** (전 직업 동일 · 칸 = 묶음 단위, 1묶음 ≈ 10마리) |
| 발록전 동행 | **불가** — 마을 방어 전용 |
| 사망 | 영구 소실 |
| AI | 배치 조작 없음. 모집 즉시 **현재 최전방 시설(포탑 → 억제기 → 넥서스) 앞으로 자동 집결**(맵 넘어감). 시설 파괴 시 다음 시설 앞으로, 재건 시 다시 전진 |
| 이동·교전 | 추격 없음. **하단 길 위를 직진**하며 마주치는 적과 교전, 위 발판으로 올라가지 않음. 타겟 = 최근접 적 |
| 훈련 단위 | **몬스터 종류(병과) 단위** — 같은 종류 전체와 이후 모집분에 적용 |

### 2-4. 파괴 시 복구

| 시설 | 재건 가능? | 비용 | 비고 |
| --- | --- | --- | --- |
| 포탑(억제기 존재시) | ✅ | 빅토리아 주화 30 | 재건해도 전선은 앞 맵으로 되돌아가지 않음 — 현재 전선에 남은 미니언만 막음 |
| 억제기 | ✅ | 빅토리아 주화 50 | 재건 시 넥서스 노출·미니언 강화 해제 |
| **넥서스** | ❌ | **재건 불가 = 탈락** |  |

## 4. 발록 재화 확정 — "발록의 심장"

즉시 종료라서 **매치 내에서 쓸 일이 없음.** 그래서 계정 영구 보상으로 확정함. GDD의 "매치/계정 성장 분리" 원칙과 맞음.

| 보상 | 내용 |
| --- | --- |
| **발록의 심장** | 계정 영구 재화 |
| 용도 | 도감 등록, 칭호 획득, 계정 코스메틱 해금 |
| 매치 영향 | **없음** — 다음 매치가 유리해지지 않음 (형평성) |

**신규 유저가 불리해지지 않음.** 발록의 심장은 순수 기록·자랑용임.

이게 몇 개 있어야 ★ x 2개 이상의 난이도에 도전 가능 — 난이도는 **로비에서 매치 전체 난이도로 선택**하며 **참가자 전원**이 요구 개수를 충족해야 한다.

난이도 별로 몬스터들의 체력이나 보스 몬스터 클리어의 난이도가 달라짐.

예시)

난이도 : ★ → 발록이 너무 약해서 20렙에도 그냥 솔플 가능. (입장권 재화도 낙인의 영혼석 1개 필요)

난이도 : ★★★★★ → 발록이 매우 강해서 30렙에 강화도 잘 하고 컨트롤도 요구함. (입장권 재화도 낙인의 영혼석 20개 필요 → 어차피 사냥을 하면 얻고, 사냥을 해야 세지니까 자연스러운 설정)

## 5. 직업별 발록전 성격 (요청 반영)

체력↔공격력 트레이드오프로 **5직업이 발록전에서 완전히 다르게 플레이**하게 설계함.

| 직업 | HP | 발록 DPS | 90초 안에 깎는 양 (발록 HP 대비 비율) | 필요 도전 횟수 | 사망 위험 |
| --- | --- | --- | --- | --- | --- |
| ⚔️ **전사** | **최고** | 낮음 | 약 55% | **2회** | 매우 낮음 |
| 🔮 **마법사** | **최저** | **최고(버스트)** | 약 100% | **1회** | **매우 높음** |
| 🏹 **궁수** | 낮음 | 높음(안정) | 약 85% | 1~2회 | 중간 |
| 🗡️ **도적** | 최저 | **최고(조건부)** | 약 100% | **1회** | **매우 높음** |
| ⚓ **해적** | 중간 | 중간 | 약 70% | 2회 | 낮음 |

> 비율은 "1회 클리어 가능 = 100%" 기준의 상대 목표치. 절대 수치는 발록 HP(현행 157,500)와 스킬 % 배율을 함께 밸런싱할 때 정한다.

### 각 직업의 발록전 플레이(예상 및 의도)

| 직업 | 어떻게 싸우나 | 마을 비우는 패턴 |
| --- | --- | --- |
| **전사** | 안 죽고 꾸준히. 2번 나눠서 확실하게 | **길게 2번** — 예측 가능 |
| **마법사** | 궁극기로 한 번에 폭발. 성공하면 1회 클리어, 실패하면 즉사
(궁극기를 사용하기 위한 재화가 매우 많이 요구됨)
얘는 보스를 잡는 재미를 빼앗길 수 있음 | **짧고 굵게 1번** — 도박 |
| **궁수** | 원거리에서 안전하게 딜. 안정적이지만 시간 필요 | 중간 길이 |
| **도적** | 패턴을 은신으로 회피하며 극딜. 회피 실패 시 즉사 | **짧게, 반복 위험** |
| **해적** | 자체 생존력(에너지 쉴드)으로 버티며 딜. 느리지만 안 죽음 | **길게, 안전하게** |

**핵심**: 같은 발록인데 **직업마다 마을을 비우는 시간과 횟수가 다름** → 침공 타이밍도 달라짐

발록 스킬 : 

1. 점프해서 피하는 파이어볼 스킬
2. 숙여서 피하는 손톱 긁기 스킬
3. 마노 소환 (또는 좀비 머쉬맘 소환)
4. 못 피하는 화염구 소환 (못 피함)

## 6. 궁수 형평성 해결

궁수가 보스 특화라 유리했던 문제 → **마을 방어 기여를 최하위로** 조정함.

| 직업 | 발록전 강점 | 마을 방어 기여 |
| --- | --- | --- |
| 전사 | 생존력 (확실한 클리어) | **최고** |
| 마법사 | 버스트 (1회 클리어 가능) | 높음 (광역 공격) |
| **궁수** | **높은 안정 DPS** | **최하위** ← 페널티 |
| 도적 | 조건부 최고 DPS | 낮음 |
| 해적 | 자체 생존력 (재도전 불필요) | 높음 (광역 공격) |

**궁수는 발록을 빨리 잡지만, 그 사이 마을이 가장 위험함.** 실질적 트레이드오프임.
