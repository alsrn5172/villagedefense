# 테스트 임시값 — 정식 배포 전에 되돌릴 것

> 테스트(내부 Play · 시범 운영) 동안만 쉽게 하려고 바꾼 값을 여기 모은다.
> **정식 배포 = 월드를 공개로 출시해 실제 유저에게 여는 판. 그 전에 이 표를 위에서부터 전부 되돌리고, 되돌린 행은 "되돌림" 칸에 날짜 · PR 을 적는다.**
> (`Sync to Remote Workspace` 는 작업 공간을 서버에 기록하는 단계고 **월드 출시** 가 따로다 — 둘 다 개발책임자 이상. **비공개 테스트 출시는 이 표를 되돌릴 대상이 아니다.**)
> 새 임시값을 넣을 때도 이 표에 한 줄 추가한다(A · B 공용 — 남의 파일 값이면 그 주인에게 알린다).

## 되돌리는 법

- `KillExpMul`: 값을 `1.5` 로 바꾸고 그 위 "🧪 테스트 임시값" 주석 한 줄을 지운다. 일반 · 엘리트 · 보스 · 미니언 처치 경험치가 전부 이 배율을 지난다(`Farm/FarmReward` · 난이도 `MATCH_EXP_MUL` 과 곱함).
- 되돌린 뒤 Maker Reimport All → Play 에서 처치 경험치 로그로 확인.
- `DevTestMode`: 값을 `false` 로 바꾼다(B 파일 — B 와 맞춘 뒤). 그러면 스킬 창 DEV 행이 안 생기고 F8 · F9 · F10 요청은 서버가 무시한다. 되돌린 뒤 Reimport All → Play 에서 F9 를 눌러 스킬이 안 오르는지 로그(`[Skill] [DEV] ... ignored (DevTestMode=false)`)로 확인.
- 공개 출시 전 같이 볼 것(이 표의 행은 아니고 확인만): `MatchSessionLogic.Profile` 기본값이 `LIVE` 인지 · `DevStatRemote` 는 서버가 Maker Play 가 아니면 스스로 꺼진다(`IsMakerPlay` 가드).
