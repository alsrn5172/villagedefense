# 1.0.14 — 플레이 중 반복 진단 로그 정리

- 명중 판정(HIT/MISS), 오라 상태, 메소·아이템 획득, 투사체·스킬·버프·쿨타임의 반복 진단 로그를 기본 비활성화했다. 일반 경고·오류는 유지하고, MP 차감 기능 미연결 메시지 두 곳은 경고로 남긴다.
- 1.0.12 치명타 공식 수정 과정에서 누락된 MISS 스킨 속성 두 개를 원래 ID로 복구했다. 빈 skinId로 PlayTextDamage를 호출하지 않도록 방어한다. 명중 공식과 정상 MISS 표시는 유지한다.
- 개발 중 필요하면 해당 스크립트의 LogDiagnostics, SkillDatabase.LogHitRolls, FactionAuraController.LogAuraDiagnostics를 켠다. 기존 세부 진단 설정은 함께 적용된다.
- 사용자 요청으로 서머솔트 킥 판정 수정은 별도 후속 작업으로 미뤘다. 이번 변경에는 판정·범위·반복 시전 수정이 없다.

## 검증

- 변경 스크립트 16개 구문 검사 통과(mLua continue는 검사 시 Lua break로 변환). 한글 UTF-8·기존 줄바꿈 보존 확인.
- 일반 로그를 정리한 13개 스크립트: 로그·진단 설정을 제외한 Lua AST가 변경 전과 동일하다.
- 실제 Lua에서 MISS 표시·빈 스킨 차단·HIT/MISS 판정·진단 설정·오라 로그 간격 1,166개 assertion 통과.
- check-integrity.cjs 통과(기존 맵 NPC 경고 3건).
- check-wo055.cjs: 실제 Lua 수치·상태 3,941건과 장비/강화 비스탯 효과 816조합 통과. Maker가 바꾼 ItemInfo.userdataset 메타데이터 때문에 현 작업공간의 원본 해시 검사만 실패하여, 별도 복사본에 HEAD 메타데이터를 사용해 검증했다. 실제 작업공간 메타데이터는 수정하지 않았다.
- Maker 실행·화면 검증은 사용자 담당이며 아직 확인되지 않았다. Draft 유지.
