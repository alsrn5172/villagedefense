# a/ui-click-stats — UI 클릭 통계 (Draft PR #227 · 1.1.2 로 내보냄 · base `1.1.1`)

## 2026-10-21

사용자 지시: "UI 마다 몇 번 클릭당했는지 저장해서 개발자 통계로 · 누른 사람 수 / 플레이한 사람 수로 비율까지 · 패치 버전별 · 비용 안정적으로 ·
로비 · 매치 대기 · 매치 클릭을 플레이어가 다 갖고 있다가 매치 종료마다(로비로 나갈 때) 서버에 주자 · 디스코드로 보내도 된다."

- **들고 있기(클라)** `Match/UiClickSound` — 이미 모든 버튼에 거는 클릭 훅에서 버튼 경로(`/ui` 아래)마다 수를 `held` 에 센다. 서버로 바로 보내지 않는다.
  `SkipGroups`(월드맵)도 이제 훑어 **세기만** 한다(소리는 그대로 안 냄) · `StatExcludeGroups = "DevStatRemoteGroup"` 은 안 센다.
- **한 번 받기(로비)** 새 `Analytics/UiClickStats`(@Logic) — 로비(정적 룸)에서 계정 로드가 끝나면(`PlayerDBManager` → `OnAccountLoaded`) 3초 뒤 그 클라에 `AskHeld` →
  클라가 `Report` 로 한 번 넘기고 비운다. = 매치를 끝내고 로비에 올 때마다 1번(로비로 · 보스 방 · 튜토리얼 복귀 모두). 첫 접속은 빈손이라 안 보낸다.
  서버 검사: 요청한 사람만 · 한 번만 · 버튼 300개 · 버튼당 1000 · 이름 200바이트.
- **모아 쓰기(로비)** 로비 룸 메모리에 모아 **30분마다 + 룸 끝날 때** 전역 저장소 `UiClickStats` 키 `v1.1.2`(JSON 한 덩어리)에 `UpdateAndWait`(비교 후 교체) 1번.
  다른 로비가 먼저 썼으면 다시 읽어 합치고 1번만 재시도 · 실패한 몫은 다음 회차로 · `1000005`(Credit 초과)면 통계 쓰기 1시간 정지 · 45KB 넘으면 새 버튼은 `#other`.
- **누른 사람(계정 1번)** `AccountRecordData` 새 부분 `ui` = 계정 저장 키 `UiSeen`(`AccountStorageLogic.UiSeenKey`) — **로비에서만** BatchGet 에 넣는다.
  버전이 다르면 비우고 "플레이" +1 · 처음 누른 버튼이면 "누른 사람" +1(버튼 경로는 djb2 해시 짧은 이름으로 저장 = 계정당 1KB 안팎). 깨졌으면 빈 표로 시작(로드를 멈추지 않음).
- **보기** 채팅 `!클릭`(`ChatService.RequestSend` 앞단에서 가로채 그 사람에게만 답 · 중계 안 함):
  `!클릭` 상위 15 · `!클릭 <글자>` 이름 필터 · `!클릭웹후크 <id>` → `!클릭웹후크 <토큰>`(채팅 80자 상한 때문에 둘로) · `!클릭웹후크 지우기` · `!클릭보내기`.
  개발자 = `UiClickStats.DevProfileCodes`(비어 있음 — A · B 코드를 받아 넣는다) · 목록 밖이면 "권한 없음 · 내 코드 ○○" · Maker Play 는 모두 허용.
- **디스코드** 로비가 한 시간마다 확인 → 한국시간 9시 이후 그날 미전송이면 `lastPost` 를 비교 후 교체로 잡은 한 곳만 `_HttpService:PostAndWait` 로 상위 30 표 전송.
- 계약서 `Docs/스키마-계약.md` A-4 에 `UiSeen` · `UiClickStats` 기록(사용자 직접 지시라 #40 공지 생략).

## 예상 비용 (코드로 센 추정 · 동접 80 · 1인 시간당 2판 · 로비 룸 2 · 한도 = 읽기/쓰기 각 분당 `100 + 동접×10`)

- 통계 덩어리 쓰기 ≈ 분당 0.3 · `UiSeen` 읽기 ≈ 분당 3.3(로비 입장마다 +1) · `UiSeen` 쓰기 ≤ 분당 2.7 → 한도의 ~0.4% · 지금 게임 사용량(읽기 ~24 · 쓰기 ≤80) 대비 쓰기 +4% · 읽기 +14%.
- 폐기한 첫 안(룸마다 5분에 버튼별 더하기)은 분당 140~240 = 한도의 16~27% 였다.

## 잃는 것

마지막 판 뒤 로비에서 누르고 그냥 나간 클릭 · 판 도중 접속이 끊긴 사람 몫은 빠진다(로비 버튼이 조금 적게 잡힘). "플레이" = 이번 버전에 매치를 끝내고 로비로 와서 보고한 계정.
