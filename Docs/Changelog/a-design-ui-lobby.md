# a/design-ui-lobby (디자이너 시안 UI · 매치 로비 + 방 대기 · 통합 a/design-ui 의 조각)

디자이너 시안 `01-lobby`(매치 로비) · `02-room`(방 대기)을 `LobbyGroup` 에 입힌다. 1단계 = 겉모습. 서버 파일(`MatchLobbyGateway` · `DifficultyService` · `DifficultyRule.csv`)은 건드리지 않았다.
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭은 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 서버가 새 값을 줘야 하거나 새 기능)

- **함께할 사람 명단**(고른 매치 설명의 참가자 칸) — 서버 브라우저 CSV 에 참가자 이름이 없다. 그래서 고른 매치 설명은 주인 · 인원 · 참여 비용 · 권장만.
- **방 줄마다 "심장 부족" 빨강** — 줄마다 필요 심장 수가 방 CSV 에 없다. 안내 줄의 전체 경고(빨강 받침)는 함.
- **방 제목의 난이도 이름** — 방 CSV 에 이름이 없어 브라우저에서 받아 둔 설명에서 읽는다. 브라우저를 안 거치고 들어온 경우(재접속 등)는 "★3" 만 나온다.
- **진짜 스크롤 목록 · 스크롤바** — 지금처럼 고정 6줄 + "외 N개 더 있음". 시안의 "6개 표시 · 아래로 더 보기" 문구는 스크롤 전제라 안 씀.
- **서버 카운트다운 토스트**(N초 뒤 출발합니다)가 새 판과 겹쳐 이중으로 뜬다 — 서버 파일이라 못 끔.
- 빈 목록 일러스트(시안용 게임 그림 자리) · 액자 · 설명 판 안 권장 테두리 · 바닥 띠 그라데이션 배경 — 생략.
- 닫기 · 파랑 · 금 · 강퇴 버튼의 눌림 그림은 ButtonComponent 전환(있는 것만). 카드 · 줄은 전환 없음(선택 그림만).

## 단순화한 것

- 난이도 칩(쉬움 · 보통 · 매우 어려움)은 글자 폭을 재지 않고 **고정 폭 133** · 제목 오른쪽 고정 자리(x 798). 보상 칩도 고정 폭 152 / 184.
- 카드 · 줄의 잠김 칩은 고정 폭(카드 72 · 줄 54). 자물쇠는 카드 칩에만(줄 칩에는 시안도 없음).
- 잠긴 카드 엠블럼은 회색조 필터 대신 색 곱하기(0.4).
- 경고 · 카운트다운 안내 받침은 전용 그림이 없어 `chip_red_dark` · `chip_gold_dark` 를 늘려 씀(평상은 `plate_dark`).
- 경험치 막대 · 카운트다운 막대 채움 최대 폭은 트랙 안쪽(168 · 268) — 시안 200 · 300 은 100% 에서 트랙 밖으로 넘친다.
- 계정 만렙(필요 경험치 없음)은 시안에 표시가 없어 "MAX" + 꽉 찬 막대.
- 고른 매치 설명 판은 새 매치 설명 판과 같은 높이(358) — 시안의 384 는 판 밑을 10px 넘긴다. 명단을 안 그려 자리가 남으므로 권장 줄을 판 아래쪽에 둠.
- 장점/단점 줄 나누기: 서버 문구를 " · " 로 나눠 줄마다 한 항목. 합쳐서 5줄을 넘으면(★5) 같은 부호끼리 한 줄 26자 안에서 이어 붙임. 그래도 넘으면 자름.

## 확인 전

- Play / Maker 로 본 것은 **없다.** 새 칸 위치는 시안 실측에서 계산했고 `ui_lint` 에러 0(경고는 기존 것 + 켜고 끄는 겹침). 스크립트는 LSP 이슈 0.
- 눈으로 봐야 할 것: 제목 띠 · 문장 겹침 순서 / 카드 · 줄 글자 폭(한글이 칸을 넘는지) / 바닥 띠 안내 두 줄 높이 전환 / 설명 판의 보상 · 권장 줄 위치 / 주 버튼 글자 오른쪽 치우침 / 방 패널이 기본 채팅 · 환영 문구를 피하는지 / 카운트다운 판이 위 가운데 다른 UI 와 겹치는지.
