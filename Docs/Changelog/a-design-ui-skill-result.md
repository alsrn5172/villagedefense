# a/design-ui-skill-result (디자이너 시안 UI · 스킬창 + 매치 결과 · 통합 a/design-ui 의 조각)

디자이너 시안 `08-skill`(스킬창 · 8상태)과 `17-result`(매치 결과 · 3상태)를 `SkillWindow` · `MatchResultGroup` 에 입힌다. 1단계 = 겉모습.
서버 파일(`MatchSessionLogic` · `RankRewardService`) · 서버 문자열 형식 · CSV(`SkillInfo.csv` 포함) · `Skill/**` 의 다른 파일 · `Job/**` · `PlayerAttack` · `Stat/StatUIController` 는 건드리지 않았다.
고친 스크립트: `Skill/SkillWindowLogic.mlua`(B 폴더 · 디자이너 시안 반영은 A 가 한다는 합의) · `Match/MatchResultUIController.mlua`.
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭 · 행 폭(스크롤 패딩) · 툴팁 안쪽 배치는 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 서버가 새 값을 줘야 하거나 에셋이 없음 · 단순화)

- **보상 칸 분리**(시안 #14~#16: "N위 보상" · "발록의 심장 +6 (보유 11)" · "계정 경험치 +120 Lv3 → Lv4" 를 칸마다 따로) — 서버 문자열을 나누지 않기로 해서 한 줄 글 그대로. 칸 둘은 아이콘 표식만. **경험치 보조 줄 "Lv3 (40/80)"** 는 서버가 현재/필요 경험치를 줘야 해서 생략.
- **스킬 툴팁 수치 표의 오른쪽 정렬 열**(라벨 왼쪽 · 값 오른쪽 · 다음 값 오른쪽 끝) — 줄 단위로 쪼개지 않기로 해서 색 태그를 입힌 한 덩이 글로 대체. **MP 소모 "→ 다음 값"** 은 레벨별 MP 값이 CSV 에 없어 생략. **필요 줄 앞 체크 아이콘**(`icon_check_ok`/`icon_check_bad`)은 자리를 재는 노드가 더 필요해 색(평소 회색 · 부족하면 빨강)만.
- **창 위치 "화면 왼쪽"**(스킬창) · **툴팁이 창 오른쪽 12px 에 붙어 뜨는 것** — 지금 방식(가운데 · 커서 추종) 유지.
- **닫기 버튼 누르는 영역 88×88** — 52×52 그대로(투명 부모 버튼을 더 만들지 않음).
- **탈락한 1위의 왕관** — 안 붙임(시안 s2). **보상 칸 위치가 "최하위 보상" 제목 폭에 따라 밀리는 것** — 고정(제목 글 자체가 한 줄 글 안에 있음).
- **그라데이션**(하단 띠 배경 · 제목 양옆 금선 · 승리 금빛 번짐) · **그림자**(창 · 문장 · 툴팁) · **잠금 행 옅은 덮개** — 생략.
- **스킬 레벨 부족 행**: 시안 s6 은 "일반 행 + + 켜짐 + 툴팁에만 빨강" 이지만 "지금 표시 유지"로 **잠김 그림 + 조건 줄**로 그렸다(조건 문구는 `LockReasonText` 값 그대로 — "N차 전직 필요" · "N레벨 필요 (현재 M)").
- **한 글자줄 안 글꼴 섞기**(Lv Football 20 + "/ 5" Football 16 → 칸 둘로 나눔) · **글자 폭에 따라 달라지는 위치**(레벨 글자 뒤 칩 · 게이지 위치) — 고정 폭 + 정렬로 단순화(레벨 칸 56 · "/ M" 칸 40 · 칩은 왼쪽 300 고정).
