- `WorldMapNodes.csv` 같은 32행의 `X` `Y` 값도 같은 값으로 맞췄다(헤더 · 다른 열 변경 없음). 런타임은 표의 X · Y 를 읽지 않고 UI 엔티티 위치를 쓰지만 둘을 같게 둔다.
- 안 건드린 노드: `Nautilus_Village_MinimiShip`(그림에 아이콘이 없고 노틸러스 건물 위 현재 위치 그대로 맞음) · 꺼진 행 `Sleepywood_Village_MinimiMain` `map01~03`.

## 변환 · 대응

- 사용자 좌표 = `f01-월드맵.png`(2095×1614) 픽셀. 노드 좌표 = 판 중심 원점 · `MapArt`(판 중심 기준 `(0,-28)` · 1098×806)에 늘려 붙인 그림: `uiX = (x/2095 − 0.5)×1098` · `uiY = (0.5 − y/1614)×806 − 28`.
- 모양 → 노드: 초록 별 5 = 리스항구 길(마을 · 사냥터 3 · 보스 마노) · 보라 원 6 = 지역 끝 보스 5 + 여섯갈래길 · 파랑 원 6 = 마을 6 · 노랑 원 = 사냥터. 현재 위치와 가장 가까운 순으로 1:1(최소 거리 합).
- **사용자 파일에서 빠졌거나 틀린 것 3개**: 노랑 점 `(970, 1074)` 는 아이콘이 아니라 풀밭 위였다(헤네시스 길 · `970, 974` 오타로 보임). 헤네시스 골렘의 사원 · 헤네시스 북쪽 언덕 · 페리온 남쪽 산등성이 3곳은 그림의 아이콘 색을 검출해 채웠다 `(968,973)` `(932,1069)` `(982,391)`.
