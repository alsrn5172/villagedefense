# a/facility-hp-half — 포탑 체력 전 레벨 절반 · 페리온 억제기만 절반 (Draft PR #190)

## 2026-10-06

사용자 지시: "포탑 체력 절반으로 하자 · 각 레벨 전부 · 포탑이 때리니까 피가 생각보다 오래 버팀 · 페리온 억제기만 또한 절반 · 억제기들 중에서 가장 사기 · 넥서스는 냅둬".

- `TowerConfig.csv` `TOWER` 3행 `MaxHp`: 60,000 / 90,000 / 135,000 → **30,000 / 45,000 / 67,500**.
- 페리온 억제기: `TowerConfig` 의 `SUPPRESSOR` 행은 마을 구분이 없어, `VillageFacilityTrait.csv` 에 **행 하나 추가**(헤더 변경 없음) — `PERION · SUPPRESSOR · MAX_HP_MUL · 0.5 · 0.5 · 0.5`. 결과 **45,000 / 67,500 / 97,500**. 다른 마을 억제기(90,000 / 135,000 / 195,000)와 넥서스(150,000)는 그대로.
- `Lane/LaneStateService`: 새 `MaxHpOf(villageId, stage, lv)` = 표값 × `MAX_HP_MUL`(행 없으면 1배 · 내림 · 최소 1). 시설 HP 를 읽는 11곳(마을 상태 만들기 · 시설 상태 · 수리 · 강화 · 피격 알림 · 요약 줄 · 테스트 리모컨)이 전부 이걸 쓴다.
- `Docs/스키마-계약.md`: `TraitKey` 에 `MAX_HP_MUL` 추가 · 변경 이력 1줄(사용자 직접 지시라 #40 공지 생략).

## 알아둘 것

- 수리비 `RepairCostPerHp`(포탑 0.00067)는 그대로라 **전체 수리비도 절반**이 된다(Lv1 포탑 약 40 → 20주화).
- 미니언 웨이브 표(`MinionWave`)는 안 바꿨다. 이론상 8마리가 부수는 시간이 절반이 된다(예: 1페이즈 첫 웨이브 Lv1 포탑 30초 → 15초).
