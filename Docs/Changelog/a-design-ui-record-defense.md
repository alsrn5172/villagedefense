# a/design-ui-record-defense (디자이너 시안 UI · 마을 기록 + 방어 시설 관리 · 통합 a/design-ui 의 조각)

디자이너 시안 `11-record`(마을 기록 · 몬스터 도감 + 마을 통계) · `12-defense`(방어 시설 관리)를 입힌다. 1단계 = 겉모습. 서버 파일(`LaneStateService` · `MatchTallyService` · `VillageNpcUIController`)과 CSV · 스키마 계약은 건드리지 않았다.
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭은 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 서버가 새 값을 줘야 하거나 새 기능 · 기획 결정으로 뺀 것)

- **영문 몬스터 이름 줄**(도감 칸 · 푸터) — 데이터 열 없음(`MonsterInfo.csv` 헤더는 공지 후 단독). 줄 자리만 비웠다.
- **미해금 칸의 물음표 실루엣** — 사용자 지시로 지금처럼 그림을 어둡게만(자물쇠 배지는 붙였다).
- **통계 "전선 비공개"**(자물쇠 + 흐린 글) — 게임에 없는 개념이라 안 만들었다. 마을 없음은 지금처럼 "마을 없음" 글자.
- **통계 강화 표시 3단계 색**(+1 · +2 · +3) — 지금 규칙(색 없음) 유지 · 장비는 6줄 고정이 아니라 **장착한 것만 한 줄씩**(보조 무기 포함 · 시안 B안).
- **도감 스크롤바 손잡이가 움직이는 것** — GridView 기본 스크롤바에 그림만(트랙 · 손잡이).
- **방어선 띠 · 카드 그림을 공용 fac_* 로** — 마을별 그림 대입을 유지했다(파괴는 그림 어둡게 + 카드 잔해). 공용 `fac_tower_broken` 등은 안 썼다.
- **억제기 설명 "주변 아군 이동속도 +N%"** — 게임에 없는 능력이라 지금 문구 "파괴되면 미니언이 강해집니다" 유지.
- **주화 부족 때 버튼 은색** — 서버가 주화 부족을 안 내려 준다(권한만). 버튼 켜짐 그림은 서버 판정 그대로, 비용 글자만 붉게.
- **"위 5명만 표시" · 도감 "마을이 없어 해금 불가"** — 앞은 자리가 없어 뺐다(줄 5개 한도는 그대로), 뒤는 도움말 줄 끝에 붙였다.
- 알림 토스트(`마을이 없어요 - 넥서스를 눌러 마을을 연결하세요 (10레벨)`)는 공용 토스트 그룹 소관 — 문구만 지금과 다르다(`VillageNpcUIController.mlua` 72~73줄 · 안 고침).
- 제목 띠 좌우 금빛 선 · 창 · 푸터 그라데이션 · 그림자 · 목록 아래 흐림 · 푸터 배경 판 — 생략.

## 단순화한 것

- 제목 띠 글자 +22px 어긋남 = 글자는 가운데 · 아이콘 · 반짝이를 시안 글자 폭(146.5 / 119 / 210)에 맞춰 옮겨 흡수(게임 글꼴의 실제 글자 폭과 다르면 간격이 벌어진다).
- 도감 해금 진행 숫자 "n" 과 "/ 24" 는 두 칸(오른쪽 정렬 · 왼쪽 정렬)으로 나눴다(자릿수가 바뀌어도 안 겹침).
- 카드의 [최전방 칩] 이름 [레벨 칩] 묶음은 가운데 정렬 계산 대신 **이름 · 레벨 칩 위치를 고정**하고 최전방 칩은 이름 왼쪽에 둔다(시안은 묶음 전체가 가운데).
- 카드 시설 그림 칸 66×66(시안 폭 100 은 비율 모름 → 정사각 유지).
- `chip_blue`(최전방 · 착용) 는 테두리 합이 커서 높이를 19.5 → 22 로 키웠다. 방어선 노드 · 카드 레벨 칩 · 통계 레벨 칩은 작은 판(`chip_blue_dark_sm`) · 방어 버튼은 `_sm` 판(`btn_gold_default_sm` · `btn_blue_disabled_sm`) · 노드 게이지는 `gauge_track_sm`.
- 수비 유닛 마릿수(시안에 자리 없음)는 **수비대 표식 글자**(`수비대 N묶음 집결 · M마리`)에 남겼다.
- 수비대 표식 · 체력 게이지 채움은 기존 방식(폭 줄이기)을 유지하고 만땅 폭만 시안 값(138 · 234.5)으로.
- 장비 줄의 부위 라벨만 회색(리치 텍스트 태그) — 장비 이름 · 강화 표시는 한 색.
- 통계 "마을 성장도" 값은 지금처럼 숫자만(시안 "5 단계" 는 예시).
- 재화 그림 칸(도감 바닥 띠의 지역재화 · 꿈의 조각 · 해금 재료)은 `ItemInfo.IconRUID` 를 런타임에 넣는다(그림이 없으면 칸을 끈다).

## 확인 전 (눈으로 볼 것)

- 제목 띠 아이콘 · 반짝이 위치(글자 폭 추정) · 제목이 NPC 이름에서 "몬스터 도감" / "마을 통계" 로 바뀐 것.
- 도감 칸: 6열이 한 줄에 맞는지(`CellSize` 139.5 · 간격 9.7) · 눈금 · 배율 · Sel / Locked 덮개가 글자 뒤에 깔렸는지 · 호버 그림.
- 도감 스크롤바가 오른쪽 20px 자리에 들어가는지.
- 푸터 세 모양(안내 + 보유 칩 / 비용 칩 / 초록 요약) · 해금 버튼 "해금됨" 체크 위치.
- 통계 줄 · 상세 판 · 칭호 있는 줄 / 없는 줄 · 긴 이름 말줄임 · 장비 글자가 받침 안에 들어가는지(보조 무기 포함 7줄일 때).
- 방어 카드: 이름 + 레벨 칩 / MAX 칩 위치 · 최전방 칩과 이름 겹침 · 파괴 카드(Dead 덮개 · 잔해 · 그림 어둡게) · 버튼 안 아이콘 · 주화 · 비용이 버튼 폭 안에 들어가는지.
- 방어선 띠 노드: 이름 · 레벨 칩 · 위치 글자 겹침 · 수비대 표식 문구 폭 · 마을 없음 화면 전환.
