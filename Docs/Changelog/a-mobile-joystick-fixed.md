## 2026-10-06

- `ui/DefaultGroup` → `UIJoystick` 의 `JoystickComponent.DynamicStick` **true → false**. 조이스틱이 누른 곳으로 옮겨 가지 않고 지금 자리(좌하단 `(310, 230)` · 200×200)에 고정된다. 좌표 · 크기 · 키 매핑은 그대로.
- 전후 비교(빌더로 7개 엔티티 전부): 달라진 값은 이 한 줄뿐.
- 로비 방 패널 [시작하기] · [나가기](`LobbyGroup/RoomHud`)가 모바일에서 안 눌리는 문제는 `DynamicStick` 이 켜진 조이스틱이 왼쪽 위 터치를 먼저 받는 것을 첫 후보로 봤다. 조이스틱 말고 로비 버튼 위에 상시 떠 있는 터치 UI 는 찾지 못했다(화면 좌표로 겹침 계산 · 평소 숨겨진 팝업 딤만 겹침).
