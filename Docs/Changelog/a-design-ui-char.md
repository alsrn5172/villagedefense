# a/design-ui-char (디자이너 시안 UI · 캐릭터 창 · 통합 a/design-ui 의 조각)

디자이너 시안 `07-char`(캐릭터 창 · 스탯 탭 + 장비 · 인벤토리 탭)를 `CharacterGroup` 에 입힌다. 1단계 = 겉모습. 서버 파일(`StatService` · `EquipService` · `InventoryService` · `SummonManager` 등)과 CSV · 스키마 계약은 건드리지 않았다. 공방 · 마을 생활 창이 같이 쓰는 `InventoryUIController.FillItemView` 는 시그니처 그대로 두고 안쪽만 고쳤다(공방 · 생활 UI 파일은 건드리지 않음).
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭 · 그림 교체는 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 서버가 새 값을 줘야 하거나 새 기능)

- **툴팁 요구 줄 빨강 + "(내 직업과 다름)"** — 클라가 내 직업 코드 · 레벨 숫자를 갖고 있지 않다(`StatUIController.SetCell` 은 표시용 문자열만 받는다). 직업 코드 · 레벨 캐시가 필요.
- **가방 → 장비 칸 끌기 · 끄는 칸 · 점선 표시(#25)** — 클릭 장착이 이미 있다. 끌기는 새 기능이라 제외.
- **벗음 알림 "○○을 벗었어요 · 가방으로"(#24 · 1.6초)** — 창 안 전용 알림이 없다(서버 응답에 토스트도 없음). 기존 전역 `_UIToast` 를 쓰려면 벗은 칸 이름을 기억해 응답 때 부르면 되는데 기획 결정(전역 토스트 vs 창 안 판)이 남아 있어 제외.
- **칸 "누름" 상태(금테 + 살짝 눌림 0.97배)** — 스크립트로 스케일을 쓰는 방식이 필요해 제외(마우스 올림 금테까지만).
- **가방 스크롤 막대 트랙 · 손잡이(#20)** — GridView 스크롤 위치를 읽는 API 를 못 찾았다. 그리드에 기본 스크롤 막대(자동 숨김)가 있어 그대로 둠.
- 무대 배경(초상화 · 장비 판 "밤 성" 그림)은 시안용 임시라 적용 대상이 아니다 → `panel_inner` 채움 판 + 아바타. 그림자(drop-shadow) · 제목 양옆 가는 선(그라데이션) · AP 칩 테두리 1px · 정보 줄 이름표 그라데이션 배경 · 설명 줄 간격 1.5 — 생략.
- 능력치 줄 아이콘: HP · MP 는 대응 에셋이 없어 아이콘을 끈다(`icon_stat_magic` 은 마력에 씀).
- 장비 칸 "한벌옷" 잠김은 클라가 상의 아이템의 `AvatarSlot == LONGCOAT`(`ItemCatalog:IsLongcoat`)로 판단한다.

## 단순화한 것

- 탭 · 스킬 버튼 · 분류 칩 · 장비 칸 · 자동획득은 **ButtonComponent 전환을 끄고(Transition None) 스크립트가 그림 · 글자색을 바꾼다**(선택 상태를 따라 그림이 바뀌어야 해서). 그래서 이 버튼들의 눌림 그림(`btn_blue_pressed` 등)은 없다. 닫기 · 자동 분배 · "+" 는 ButtonComponent 전환(올림 · 비활성 그림)을 쓰고, 자동 분배 · "+" 는 스크립트도 비활성 그림을 명시로 바꾼다.
- 탭 글자는 아이콘 자리만큼 왼쪽 여백(Padding left 30 → 글자가 15px 오른쪽)으로 민다(글자 폭을 재지 않음).
- 경험치 막대는 고정 140×20 · 채움 최대 폭 108(트랙 − 32). 분모가 없는 표기(만렙)는 꽉 찬 막대.
- 툴팁 능력치 줄 이름표는 x 28 · 폭 82(아이콘 자리를 비움 · 시안은 이름표 폭 110 안에 아이콘 + 글자).
- 강화 배지는 +3 을 넘어도 +3 그림. 툴팁 강화값 색은 금(#E8B64C) · 보석은 보라(#C3A6FF).
- 9-slice 두께가 시안과 다른 곳: `chip_gold` 10(시안 12) · `slot_frame_sm` 10(시안 12) · `btn_blue_pressed` 는 Simple 그림이라 탭 눌림에 못 씀.
- 닫기 버튼은 시안 52×52 그대로라 모바일 터치 크기(88)보다 작다.
