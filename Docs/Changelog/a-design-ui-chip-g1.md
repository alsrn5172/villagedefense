# a/design-ui-chip-g1 — 칩 글자 대비 2단계 · 묶음 G1 (로비 · 방 · HUD · 결과 · 관전 · 부활)

디자이너 시안 갱신(`1790779133-4234` → `1790844637-7b1e`): 칩 그림 3장(blue · green · red)이 어두워지고, 칩 위 글자에 규칙이 붙었다.
밝은 칩(`chip_gold` · `chip_gray`) = 잉크 `#1C1405` + 밝은 그림자 · 보석 칩(`chip_green` · `chip_blue` · `chip_red`) = 흰 글자 + 짙은 외곽선 + 어두운 그림자 · 좌우 여백 ≥ 테두리 + 1.
대응 표 = 시안 폴더 `spec/_plan/_chip-contrast.md`. base = `a/design-ui-chip-contrast`(1단계 · 공용 헬퍼). **Maker 로는 확인하지 않았다(파일 · 스크립트만).**

## 한 것 (파일 쪽)
- 적용 스크립트 9개 끝(글자를 다 맞춘 뒤 · write 앞)에 `S.chipText` 를 불렀다: `apply-lobby` · `apply-room` · `apply-hud-clock` · `apply-hud-status` · `apply-hud-quickslot` · `apply-hud-skill` · `apply-result` · `apply-revive` · `apply-spectate`. 전부 두 번 돌려 UI 파일 해시가 같음(멱등) · `ui_lint` 에러 0(경고는 기존 수준).
- 규칙이 걸린 글자 엔티티 49개: 로비/방 18(대기 줄 잠김 칩 6 · 난이도 카드 추천 3 · 잠김 3 · 내 레벨 칩 1 · 방 "나" 5) · 시계 2(페이즈 칩 · 파병 배지) · 상태창 3(키 칩 C K F) · 퀵슬롯 2 · 스킬 칸 5 · 결과 18(사유 칩 3 · "나" 5 · 순위 5 · 탈락 5) · 부활 1(자동 칩) · 관전 0(탭 기본 그림이 어두운 칩).

그림 교체가 없는 칩(로비 잠김 · 추천 · 방 "나" · 키 칩)은 파일 규칙만으로 충분해 컨트롤러는 안 고침. 공용 헬퍼 · `skin.cjs` · `ruid-map.json` 은 안 고침.

## 안 한 것 · 확인 못 한 것
- `apply-guide` · `apply-popup`: 칩 쓰는 엔티티 없음. 시안의 "0페이즈 개척"(05-guide · 06-popup 안)은 시계 목업이고 게임에선 실제 `MatchClockGroup` 의 페이즈 칩(위에서 처리).
- 가이드 "안내 켜기" 칩은 버튼 `Chip`(칩 그림 아님) → 대상 아님.
- 외곽선 굵기 `CHIP_OUTLINE_WIDTH = 0.25` 는 추정치(1단계와 동일 · 눈으로 보고 `skin.cjs` + `UiChipText.mlua` 두 곳을 같이 조정).
- `RectOffset.Clone()` 으로 `Padding` 을 고치는 `SetPhasePadding` 은 Play 로 아직 안 돌려 봄.
- `.codeblock` 은 안 건드림(Maker Refresh 가 만듦).
