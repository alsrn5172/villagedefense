### 설계 판단

- **발록 HP 를 따로 저장하지 않는다.** 코드로 확인했다: 보스 HP 자연회복 없음(`Monster` 가 HP 를 채우는 곳은
  스폰과 `Respawn()` 뿐인데 보스는 꺼져 있다) · 플레이어가 방을 나가면 `StateChaseMonster.IsTargetValid` 가
  **맵 검사로 먼저** 대상을 푼다(`KeepTargetForever` 보다 앞) · 빈 방에선 `DistanceToTarget = 99999` 라
  스킬이 하나도 안 나간다(소환도 안 쌓인다). **발록 엔티티 자체가 장부다.**
- **누적 피해 = `MaxHp - 현재 HP`.** 1인 1방이라 자기 방 발록에 준 피해가 곧 그 사람 것이다.
  결과 화면의 `damage = 0 -- TODO(WO-017)` 두 곳을 이걸로 채웠다. 승자는 MaxHp 라 순위 맨 위다.
- **매치 시작 때 6방 발록을 새로 깐다.** 사용자는 "매치가 끝나면 맵이 폐기된다" 로 알고 있었는데
  **실제로는 안 없어진다** — 발록 방은 `IsInstanceMap: false`(정적 맵)이고 코드 전체에 보스를 리셋하는 곳이 0곳이다.
  안 깔면 다음 판이 ① 죽은 방(5분 뒤에야 재생성) ② 깎인 HP 를 물려받는다.
  리스폰을 끄는 것만으로는 **이긴 사람 방의 발록이 영영 안 나온다.**
- **발록 입구는 `LoadRoutes` 에서 거른다.** `BindRow` 에서 건너뛰면 `AttemptBindings` 가 완료로 안 세서
  `RetryTimeout`(8초) 뒤 "해석 실패" 경고를 잘못 남긴다. 클라 ↑키는 표를 직접 읽으므로 그 행을 여전히 찾는다.
- **도착 유예.** `MoveToEntityByPath` 직후엔 아직 마을에 있다. 다음 틱에 "방 밖" 으로 읽으면 들어가자마자
  쫓겨난다 → `moving → in` 두 단계로 두고 **도착해야 90초를 센다.** 8초 안에 안 나타나면 이동 실패로 푼다.
- **방 안 사망.** 엔진이 5초 뒤 **그 방의 SpawnLocation** 에 되살린다(`PlayerComponent.Respawn`:
  RespawnPosition → 맵 SpawnLocation → 입구). 사망하면 점유를 풀고, 되살아나면 마을로 꺼낸다.
- **탈락자.** `SpectateService.Enter` 는 캐릭터를 숨기고 멈추기만 하지 옮기지 않는다 → 방 안에서 탈락하면
  꺼낸다. 배정은 유지한다.
- **선취 판정 1회.** `BalrogRoomService.DeclareWinner` 가 `Winner` 로 막고, `MatchSessionLogic.Expire` 가
  한 번 더 막는다. 같은 틱에 둘 이상 죽으면 방 번호가 빠른 쪽 (결정적). 클라가 "이겼다" 를 보내는 경로는 없다.
- **리셋 실패 방은 판정에서 뺀다.** `lastHp` 를 안 채워서, "없는 발록" 이 죽은 것으로 읽혀 가짜 승자가 나오지 않게.

### 🔴 검증 과정에서 뒤집힌 전제

| 전제 | 실제 |
|---|---|
| "다른 보스도 리스폰 안 된다" | **된다.** `Monster.RespawnOn` 은 꺼져 있지만 `BossSpawner` 가 따로 `RespawnSeconds`(8종 전부 300) 뒤 새로 깐다 |
| "매치 끝나면 맵 폐기" | 정적 맵이라 **안 없어진다** → 매치 시작 리셋 |
| "탈락하면 관전으로 빠진다" | 관전 진입은 **옮기지 않는다** → 방에서 꺼내야 한다 |
| "방에서 죽으면 나간다" | 엔진이 **그 방 안에** 되살린다 → 부활 뒤 꺼낸다 |

**⚠️ 규칙 판단 1개 — 사용자 확인 필요.** 90초 마감 **뒤에** 들어간 처치(내보내는 1초 사이, 나간 뒤 소환수 등)를
**무효**로 하고 그 방 발록을 풀 HP 로 새로 깐다. 두 Codex 모두 "마감 뒤 처치는 무효" 였고 GDD 의 90초 제한과도 맞지만,
그 사람은 그때까지 깎은 HP 를 잃는다. 인정으로 바꾸려면 `CheckBosses` 의 한 줄이다.
