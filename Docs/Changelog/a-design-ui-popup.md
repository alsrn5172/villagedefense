## 안 한 것 (2단계로 넘김)

- **급한 목표(붉은 바)**: 그림 · 노드(`Bar/BarWarn` · `Bar/FlagWarn`)는 꺼 둔 채 준비, 어느 목표가 급한지는 서버 데이터가 필요 → `GuideUIController.SetUrgent(true)` 를 부를 곳만 남김.
- 관전 바 눈 · 이동 화살표 · 문 아이콘 — 대응 에셋 없음(생략). 따라가는 사람 강조는 서버가 안 알려 줘 클라 기억으로만.
- 확인 창 높이 가변(문구 줄 수) — 고정 332. 토스트 판 폭이 글자에 맞춰 줄어드는 것 — 두 종류 고정 폭.
- 화면 막 그라데이션 · 그림자 전부 생략(단색 · `#060A14` 60%).
- 툴팁 · 버튼 올림 그림이 `_sm` 이 아닌 곳(안내 끄기 눌림 = `btn_blue_pressed` 는 큰 판을 늘려 그림).
