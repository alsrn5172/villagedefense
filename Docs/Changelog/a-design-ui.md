# a/design-ui (디자이너 시안 UI 전체 적용 · 통합 · Draft PR #131)

디자이너 시안(21창 · 2026-10-01 반영본)을 게임 UI 에 입힌다. 1단계 = 겉모습(판 · 버튼 · 칩 · 글꼴 · 색 · 배치 · 상태 그림). 서버 뷰 형식 · CSV 헤더는 건드리지 않는다.
그림은 그룹 리소스(`mIYbC` · 이름 `dui_*`)에 올리고 저장소에는 이름 → RUID 표만 둔다.

### 못 본 것 · 눈에 띈 것

- 서버가 실제로 보내는 값으로 뜨는 경로는 대부분 안 탔다: NPC 클릭 → 창 열기(`ReceiveNpcOpen` 직접) · 모집/강화/해금 실제 요청(모집 3회 · 마을 소유 · 포탑 손상 · 파괴는 시험 시드) · 통계 생존자 목록(클라 주입 — 서버 요청 `RequestStatDetail` 이 응답으로 덮으니 `OnView` 직접) · 월드맵 노드 마우스 올림(`ShowTooltipAt` 직접) · 레벨업 알림(`PlayLevelUp` 직접) · 쿨 오버레이(클라 주입 — HP 물약 쿨 키 버그는 그대로) · 매치 결과(`SetResultCsv` 주입).
- 버튼 올림/누름 그림(마우스) · 칸 4상태 중 "마우스 올림" · 모집/강화 직후 토스트는 안 찍었다.
- **방어 시설 · 마을 없음(E01)**: 토스트(`UIToast` 2.1초)가 창 위쪽에 겹쳐 뜬다 — 시안 s4 도 "빈 화면 + 위쪽 알림" 이다. 토스트가 사라진 뒤의 빈 창은 따로 안 찍었다.
- 🔴 **월드맵 파병 리모컨(F04)**: 판이 흰 바탕 · 옛 모양 그대로다(조각 체인지로그 대로 "열리지 않는 레거시 패널" · 시안 없음) — 디자인 대상에서 뺄지 결정 필요.
- 🔴 **시설 오라 띠(W02)**: 억제기 오라가 **안 보인다**. 렌더 층이 `MapLayer0 / OrderInLayer 3`(시설 · 플레이어 뒤)이라 이 테스트맵 배경(`Default` 층 · 시설 위치와 같은 높이)에 가려진다. 층을 `Default/140` 으로 올리면 하늘색 띠가 발판 위로 은은하게 보인다(`W02b` 가 그 모양 · 파일만 저장 — 코드는 안 바꿈). 층을 올릴지는 기획 결정(`AuraEmitter.AuraOrderInLayer` 한 값 · 실제 레인 맵 배경에서는 원래 층으로도 보일 수 있다 — 테스트맵 한 곳만 본 것).
- 시설 체력 바: 시안의 틀은 9-slice 인데 월드 SpriteRenderer 라 고정 그림을 늘린 것(조각 체인지로그 대로). 채움 색 전환은 초록(전체) · 노랑(40%) · 빨강(25% 이하 · 앞 일부만) 세 가지를 캡처했다 — 부드럽게 줄어드는 움직임과 파괴 때 숨김은 안 봤다.
