# a/design-ui (디자이너 시안 UI 전체 적용 · 통합 · Draft PR #131)

디자이너 시안(21창 · 2026-10-01 반영본)을 게임 UI 에 입힌다. 1단계 = 겉모습(판 · 버튼 · 칩 · 글꼴 · 색 · 배치 · 상태 그림). 서버 뷰 형식 · CSV 헤더는 건드리지 않는다.
그림은 그룹 리소스(`mIYbC` · 이름 `dui_*`)에 올리고 저장소에는 이름 → RUID 표만 둔다.

- 서버가 실제로 보내는 값으로 뜨는 경로는 안 탔다: NPC 클릭 → 창 열기(공방 · 파병은 컨트롤러 `Open` 직접 · 차원 관문도 `Open('dimensiongate')` 직접) · 강화/제작/구매 실제 요청 · 파병 접수 실제 대기열 · 계정 창의 업적 "달성 · 받음" 상태와 기록 탭 실제 데이터(기록 탭은 CSV 를 `RenderHistory` 에 주입 · 도감은 서버 응답 위에 칸 3개 값만 덮음).
- 버튼 올림/누름 그림(마우스) · 칸 4상태 중 "마우스 올림" · 강화 성공/실패 결과 문구 · 제작/구매 직후 토스트는 안 찍었다.
- 🔴 캐릭터 창 스탯 탭의 **이름 칸이 "플레이어"** 로 보인다(`StatService.BuildUiCsv` 가 name 키를 안 보냄 · 요청 사진 때부터 열려 있던 질문). 닉네임을 넣을지는 기획 결정.
- `ReceiveNpcOpen('…', 'VD_COMMON_DIMENSION_GATE')` 경로는 이번엔 관문 대신 파병 라우트로 열렸다(로그는 route=dimensiongate 로 요청 · 창은 dispatch · 원인 미조사 · 관문은 Hidden 이라 실게임엔 영향 없음).
