# a/design-ui-life (디자이너 시안 UI · 마을 생활 · 통합 a/design-ui 의 조각)

디자이너 시안 `10-life`(창고 · 모집 · 조련 · 10상태)를 `VillageLifeGroup` 에 입힌다. 1단계 = 겉모습. 서버 파일(`LaneStateService` 등) · CSV · `VillageNpcUIController` · `InventoryUIController` 는 건드리지 않았다. 고친 스크립트는 `Npc/VillageLifeUIController.mlua` 하나.
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭은 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 새 기능이거나 서버가 새 값을 줘야 하거나 에셋이 없음)

- **영문 몬스터 이름 줄**(카드 · 선택 요약 · 조련 줄) — 데이터가 없다(MonsterInfo 에 영문 열 없음 · 헤더 변경은 공지 후 단독). 줄 자체를 생략했다(조련 줄의 이름은 줄 가운데로).
- **도감 단계 아이콘 대응**(Lv 1~5 ↔ stage_1~3) — 기획 결정이라 시안 그대로 전부 `stage_3` 를 그린다.
- **시설 공용 아이콘**(포탑 · 억제기 · 넥서스 · 파괴) — 마을별 RUID · 상하반전을 서버가 실어 보내므로 공용 `fac_*` 로 바꾸지 않았다. 자리만 58×58 로. 부서진 시설은 `fac_*_broken` 대신 지금처럼 어두운 붉은 색조.
- **재료 7종 새 그림** — 게임 그림 자리라 원작 아이콘 그대로(칸 · 칩 크기만 시안에 맞췄다).
- **그라데이션**(화면 막 · 바닥 띠 · 제목 양옆 선 끝 · 창고 판 초록 기운) · **점선 빈 카드 윤곽**(모집 · 조련 빈 상태) — 에셋이 없어 생략하거나 단색으로(바닥 띠 = 어두운 남색 단색 + 위 금선 · 제목 양옆 선 = 얇은 금선 50%).
- **재료 부족 빨간 테**(비용 칩 · 재료 칩) — 전용 에셋 없음 → `plate_dark` 를 붉게 곱해 대체. **부족 카드의 몬스터 틀 채도 낮춤** — 생략.
- **한 글자줄 안 글꼴 섞기**(이름 Maple + 영문 Noto · 수량 18 + 14) — 못 해서 한 글꼴 + 색 태그(`<color=…>`)만.
- **글자 폭에 따라 움직이는 배치**(시설 이름 옆 안내 · 칩 폭 · 제목 장식) — 고정 자리로 단순화(아래).
- **조련 목록 스크롤**(8종 초과) — 새 기능. 지금처럼 8행 + "n종 더 있음".
- B 코드(`Skill/**` · `Job/**` · `PlayerAttack.mlua`) — 건드릴 것 없음.

## 단순화한 것 (시안과 다른 곳)

- **조련 줄 62 → 54 · 간격 8 → 7**: 시안 목록 영역은 6행인데 게임은 8행이라 줄을 낮춰 시안 영역(270~751) 안에 8행을 넣었다. 줄 안 요소는 전부 줄 가운데 기준이라 시안과 같은 모양.
- **제목 장식**: 글자 폭을 재지 않으므로 "창고지기"(좁은 벌)와 "몬스터 모집관 · 몬스터 조련사"(넓은 벌) 두 벌을 깔고 라우트로 하나만 켠다. NPC 이름이 다른 길이면 글자와 장식 사이가 벌어질 수 있다.
- **시설 이름 옆 안내 글**("모집하면 여기 바로 집결"): 가장 긴 이름(억제기) 기준 x 고정.
- **모집 카드 재료 칩 폭**: 시안은 부족일 때 74.5 · 아니면 82.5 → 82.5 고정(받침 색만 붉게). **푸터 비용 칩**은 시안대로 162 / 194.5 두 폭(받침만 폭을 바꾼다).
- **수량 받침 폭** = 8.5 + 8 × 자릿수(시안 실측 16.5 / 24.5 와 같다).
- **푸터 "재료" 필요 수 · "보유" 글자 간격**: 필요 수가 두 자리면 4.5px 붙는다(시안은 글자 폭에 맞춰 밀린다).
- **고른 아이템 줄 "이름 × 수량"**: 이름 글꼴(Maple 18) 한 줄에 수량을 금색 태그로 붙였다(시안은 수량만 Football 18).
- 조련 줄의 "강화" 버튼 눌림 그림 = 기본 그림(`btn_gold_pressed` 는 26px 판이라 16px 판과 안 맞는다 · `_sm` 눌림 판 없음).
