## 변경 내용

- 치명타 확률: 기본 5% + 최종 LUK × 직업 효율 ×0.3%p + 도적의 럭키 세븐 학습 레벨 ×10%p. 표시 원확률과 실제 100% 상한을 구분한다.
- 치명타 데미지: 200% + max(최종 LUK−400,0) × 직업 효율 ×0.3%p + 활성 쉐도우 파트너 레벨 ×6%p. 확률 초과분 전환을 제거했다. 닷지의 확정 치명타·200% 특수 규칙은 유지한다.
- 스킬 학습·초기화·직업 변경·버프 시작/종료와 공통 스탯·전투력·표시 갱신을 연결했다. 쉐도우는 활성 버프의 레벨 스냅샷을 사용한다.
- 10/15/20/25제 장비의 기본·고정 강화 4대 스탯과 스탯 보석만 변경했다. 30제·앱솔랩스 기본 스탯 및 모든 기존 비스탯 옵션·강화 비용은 유지한다.
- 25제 두 부위 몫의 +0~+3 총량은 주스탯 44/59/73/88, 부스탯 15/19/25/29. 일반 곡선을 먼저 반올림한 뒤 두 배 하지 않는다.
- 스탯 보석 실제 1개당 10/15/20/25/30제 +6/+8/+8/+10/+12. 15/25 티어 행의 다른 보석 효과는 기존 실효 티어와 같다.
- 앱솔랩스 한벌옷 5종에 추가 공속 +10%. 강화·부위 배수 없이 서버 최종 스탯에서 합산하고 클라에 전달한다. 사용자 확정에 따라 어벤저 ×0.60 유지, 옷 조합 ×0.66.
- 15개 스탯의 설명 오버레이를 추가했다. 서버가 설명 수치를 구성하며 라벨/값 hover, 탭/닫기/맵 변경 숨김과 AP 버튼을 가리지 않는 배치를 적용했다.
- 장비 레벨 차 알림만 Lv16부터 발생하게 하고 표시 직전에도 레벨·현재 장비를 재검사한다.

- 변경 스크립트 14개 Lua 구문 검사 통과. UIBuilder 구조 검사 통과. 기존 UI 231개 항목의 ID·배치 유지, 설명 패널/제목/본문 3개 항목만 추가.
- UTF-8 엄격 디코딩과 대체문자 검사를 수행했다. 한글 렌더링·겹침은 Maker에서 확인할 항목이다.

## 재현 방법과 범위

`check-wo055.cjs`는 기본 실행 시 추가 패키지 없이 CSV/스키마/기존 옵션 보존을 검사한다. `--lua-module`에 Fengari 모듈 경로를 주면 실제 게임 스크립트를 Lua로 변환해 순수 계산과 상태 갱신을 함께 검사한다. 검증 의존성은 저장소 밖에 설치했으며 게임 패키지에 추가하지 않았다.

이 검사는 Maker 빌드/Play 결과가 아니다. 사용자 지시에 따라 Maker Refresh·빌드 로그·Play·화면 캡처는 수행하지 않았다. UI hover/잘림/겹침/AP 클릭, 실제 기본 공격·어벤저·궁극기·분신, 버프 사망 해제와 매치 전환은 사용자 Maker 검증 후 확정한다. 캡처 보고서도 그 단계에서 보완한다.
