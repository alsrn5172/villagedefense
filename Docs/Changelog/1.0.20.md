# 1.0.20 — 버그 · UI 수정 (사용자 지시 2건 · 2026-10-19)

## 안내 카드
- (1-1) "나보다 5레벨 이상 낮은 몬스터를 20마리 잡았어요" 카드(`huntlevel`)가 판 시작부터 누적으로 세어, 낮은 레벨 때 잡은 수가 레벨이 오른 뒤에도 남아 엉뚱하게 뜨던 것: `Guide/GuideService.mlua` `OnLowMonsterKilled` 가 **지금 레벨에서 잡은 것만** 센다(`lowKillsLevel` · 레벨이 바뀌면 0 부터).
- (1-2) "수비대를 모집하세요" 카드(`recruit40`)가 이미 모집한 뒤에도 뜨던 것: 예전엔 `MAT_` 재료 최대 수량 ≥ 40 만 봤다. → `GuideService.RecruitTipDue` = 이번 판에 아직 모집 안 함 · 내 마을 있음 · 수비대 칸이 남음(`#v.defenders < v.cap`) · **모집 표(`MonsterRecruit`) 재료** 하나가 40개 이상. 모집 성공 때 `LaneStateService.RequestRecruit` → `GuideService.OnRecruited` 가 이번 판 표시를 막고, 이미 보낸 카드는 `TipController.CancelTip`(Client)으로 클라 줄에서 뺀다(모집 창이 떠 있는 동안 줄에서 기다리다 창을 닫으면 그제야 떴다). 클라 `TipController.StillTrue` 도 띄우기 직전 가방 재료(`MAT_` 합 ≥ 40)를 다시 본다(도감 해금 · 창고로 재료가 줄었으면 버림).
