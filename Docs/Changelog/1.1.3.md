# 1.1.3 — 시전 중 방향키 입력 · 어벤저 픽파켓 · 메소 익스플로전 · 착용 장비 강화 · 파괴된 빅토리아 시간 (2026-10-22 ~)

계획 = 허브 `WorkOrders/WO-058-…md` · Draft PR #229.

## 1. 스킬 시전 중 누른 방향키가 버려지던 것 (`Skill/SkillCaster`)
- 증상(사용자): 럭키 세븐 · 더블 샷 · 에너지 볼트 · 스나이핑 · 어벤저는 "다음 시전은 되는데 이동은 안 풀린 것 같다".
- 원인: 이동과 시전은 같은 락(`castLockActive`)이라 같은 순간에 풀린다. 다만 땅 락 동안 `MoveLeft` / `MoveRight` 조건이 거짓이라 컨트롤러가 방향키 누름을 버리고, 풀릴 때 `ResumeHeldMove` 는 **아직 누르고 있는** 키만 다시 보냈다 → 락 중에 톡 누른 방향키는 사라졌다. 스킬 키는 꾹 누르기가 풀리는 프레임에 다시 시전해서 차이가 났다. 위 다섯 스킬은 공격 모션이 락보다 0.27 ~ 0.44초 길어 더 눈에 띄었다.
- 고침: 스킬 땅 락 동안 좌우 키 누름을 기억했다가(마지막 누름 · 누른 · 뗀 시각) 락이 풀리는 순간, 이미 뗀 키면 그 방향으로 **누르고 있던 시간만큼 걷고 멈춘다**(`KeyDown` → 그 시간 뒤 `KeyUp` + 멈춤). 아직 누르고 있으면 예전처럼 계속 걷는다(`ResumeHeldMove`).
  - 기억하지 않는 락: 기본 공격 · 궁(ORIGIN) · 붙잡는 락(콤보 데스폴트). 공중 시전은 착지해 땅 락이 된 뒤부터.
  - 풀리는 프레임에 꾹 누르기 재시전이 걸리면(스킬 키를 누르고 있음) 남은 걷기는 다음 락으로 다시 미뤄진다.
  - 락 길이 · 시전 간격 · 서버 판정은 그대로(DPS 변화 없음). 스위치 `SkillCaster.DeferMoveInputDuringCast`(기본 true).

## 2. 어벤저 픽파켓 = 동전 3개 (`Skill/SkillBuffs` · `Skill/SkillWindowLogic`)
- 사용자: "어벤저가 얻는 픽파켓 3배는 메소 개수가 3개인 거지 메소량이 3배가 아님 · 메소 익스플로전에서 이득 보게".
- 예전(1.0.11 ~ 1.1.2): 어벤저 한 타 = 값 ×3 동전 1개(`OnSkillHitMonster` 의 `value * 3`). → 같은 값(1~2 메소) 동전 **3개**(`SkillBuffs.AvengerPickpocketCoins` 3). 세 개는 맞은 몬스터 발 아래 줄의 다음 칸에 나란히 놓인다. 소리는 한 타에 한 번. 메소 익스플로전은 동전 하나 = 한 번 폭발이라 어벤저로 모은 동전이 3배로 터진다.
- 쉐도우 파트너 쿨 감소 타수는 그대로 1(훅은 한 번만 불린다).
- 쉐도우 파트너 스킬 창 효과 줄 "픽파켓 메소 3배" → "픽파켓 메소 3개".

## 3. 메소 익스플로전 · 픽파켓 줍기 토글
- 사용자: "동전 찾는 반경은 맵 전체로 · 캐릭터 주위 반경은 없는 거로 · 메소 없는데 터지면 이상하니까 궁 쓰면 캐릭터 주변에 메소 7개를 -3.0 부터 3.0 까지 추가로 뿌려" · "픽파켓 동전 줍기 off 는 픽파켓에 놔라".
- `Skill/SkillExecutors`:
  - 동전 찾기 = **맵 전체**(`MesoSearchWholeMap` true · 같은 맵 · 내 동전 · 안 주운 동전만 · CSV Range 6 은 끌 때만).
  - 시전 때 캐릭터 발 높이 **x −3 ~ +3 에 메소 7개**(`MesoSummonCount` 0 → 7 · `MesoSummonSpread` 3.0 · 1.0 간격 · 예전 무작위 자리 코드 대체). 소환 동전도 동전 하나 = 50% 1타 · 그 자리 반지름 1.0 안 적을 대상으로 잡는다 → 캐릭터 주변 적이 맞는다.
  - 동전이 없어도 시전된다(소환 7개만 터짐 · `PreCheck` 의 "no meso nearby" 거절이 사실상 없어짐).
- 픽파켓 줍기 토글(스킬 창 **픽파켓 줄** · 소리 칩 바로 오른쪽 "줍기" 칩):
  - 끄면 내 **픽파켓 동전만** 줍지도 끌어오지도 않는다(`Farm/MesoCoin.PickpocketPickupBlocked` · 서버 판정 · 몬스터 드랍 메소는 그대로 줍는다 · 동전 수명 60초 그대로).
  - 계정 저장: `AccountProfile.account_pickupOff`(**SchemaVersion 8 → 9** · 기본 `false` = 주움 · 옛 저장 = 주움) · `AccountData.Is/SetPickpocketPickupOn` · `SkillBuffs.RequestSetPickpocketPickup` / `SyncPickpocketPickup`(창을 열 때 `RequestPickpocketSoundSync` 가 같이 보낸다).
  - 칩: 행 템플릿에 노드가 없어 픽파켓 줄을 만들 때 `BtnSound` 를 복제해 `BtnPickup` 으로 쓴다(`.ui` 그대로). 두 칩이 한 줄에 들어가도록 **글자에서 ON / OFF 를 뺐다**(사용자 선택 "글자 줄여 나란히") — "소리" · "줍기" · 켜짐 = 금 칩 · 꺼짐 = 회색 칩.
- 문구: `SkillInfo` SK_T31 · SK_T12 설명(+ `#Note` 끝 기록) · 스킬 창 메소 익스플로전 효과 줄("없으면 시전 불가" 삭제).
- 계약서: `Docs/스키마-계약.md` `AccountProfile` 줄에 v9(사용자 지시 변경 · 공지 생략 규칙).
