# a/design-ui-account-npc (디자이너 시안 UI · 계정 창 + 파병 접수 + 차원 관문 · 통합 a/design-ui 의 조각)

🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭은 통합 담당이 눈으로 확인해야 한다.

## 안 한 것 (2단계 · 서버가 새 값을 줘야 하거나 새 기능)

- **파병 대상 줄의 주인 이름**("단풍잎용사" 등) — 서버 뷰 V 행에 주인 이름 열이 없다(`LaneStateService` 는 안 고침). "주인 없음" 칩만 있다.
- **도감 "보스" 구분줄** — 한 GridView 는 줄 중간에 구분줄을 못 낀다(그리드 구조 변경 필요). 몬스터 · 보스가 지금처럼 이어 붙는다.
- **스크롤바 손잡이가 움직이는 것** — GridView 가 그려 주는 기본 스크롤바에 그림만 입혔다(별도 노드 없음).
- 도감 고른 칸 안내 줄의 **인라인 아이콘**(단계 · 경험치) — 색 태그만.
- **탭 · 칩 눌림 그림** — 탭은 눌림만(ButtonComponent 전환), 올림 그림은 생략.
- 제목 띠 좌우 얇은 줄 · 패널 소제목 금색 밑줄 · 하단 띠 그라데이션 · 그림자 — 생략(단색 판 / 윗선 하나로 대체).
- **차원 관문 창은 여전히 게임에서 안 열린다**(`FunctionalNpcCatalog.csv` 15행 Hidden=true · CSV 안 건드림). 확인은 `_CommonNpcUIController:Open('dimensiongate')` 나 `_VillageNpcUIController:ReceiveNpcOpen('x', 'VD_COMMON_DIMENSION_GATE')`.

## 단순화한 것

- 글자 폭에 따라 위치가 달라지는 곳은 고정 칸: 제목 앞 아이콘(NPC 이름 길이) · 업적 보상 4칸 · 기록 둘째 줄 6칸 · 하단 이동 비용 칩(이름 4글자 기준) · 보유 수비대 3조각. 글자가 길면 칸 사이가 벌어지거나 조금 겹칠 수 있다.
- 글자 안 색은 색 태그(`<color=#…>`)로. 한 글자 줄 안에서 크기 · 글꼴을 섞는 곳(N묶음의 "묶음" 작게 · 순위의 "/ N명" 등)은 같은 크기로 두거나 노드를 나눴다.
- 대기열 줄: 시안 칸(185.5) 안에 4줄이 안 들어가 **줄 높이 44 → 40 간격 44** 로 줄였다(4줄이 칸 안에 들어간다).
- 접수 중지 상태에서도 두 판 높이를 446 으로 고정(시안은 434). 빨강 띠는 판 아래 50px 로 줄여 겹치지 않게.
- 창 안 "접수 중지" 때 파병 버튼을 꺼지게 했다(시안 s2). 전에는 마을만 고르면 켜졌다 — 서버 쪽 판정은 확인 못 했다.
- 관문 안내 줄 문구는 지금 문구(개발 메모 포함)를 유지 — 시안 문구로 바꿀지는 기획 결정.
- 내 마을 카드 문구는 "내 마을 · 도보" 유지(시안 "걸어서"는 예시).
- 지역재화 "다 모으면 ✓" 는 Football 글리프 미확인이라 초록 숫자만.
- 잠긴 칸 · 흐린 문장은 회색조 필터 대신 색 곱하기(0.6).
- 아이콘은 그림 크기 비(contain)로 줄여 찌그러지지 않게 넣었다(`icon_title` 150×72 등).
- 탭 · 칸 · 행 "고름 / 잠김" 표시를 **ImageRUID 교체 대신 Sel / Locked 자식 켜고 끄기**로 했다(스크립트에 RUID 문자열을 안 흩는다 · 복제 칸 재사용에 안전).

## 확인 전

- Play / Maker 로 본 것은 **없다.** 위치는 시안 실측에서 계산했고 `ui_lint` 에러 0(경고는 작은 버튼 터치 크기 L007 · 겹침 토글 L016 등 기존과 같은 종류). 두 스크립트를 두 번씩 돌려 결과 동일 · `apply-dispatch` / `apply-gate` 는 서로 순서를 바꿔도 같다.
- 눈으로 봐야 할 것: 제목 띠 위 문장 겹침 순서 / 제목 앞 아이콘과 NPC 이름 간격 / 그리드 스크롤바 위치(오른쪽 20px 자리) · 칸 잘림 / 칸 복제본의 Sel · Locked 켜짐 / 대기열 줄 글자 폭(영문이 길 때) · 취소 버튼 클릭 / 카드의 재화 아이콘 위치 / 하단 띠 문장 ↔ 이동 비용 칩 간격 / 판 두께(9-slice 테두리) 뭉개짐.
