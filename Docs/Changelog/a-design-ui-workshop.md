# a/design-ui-workshop (디자이너 시안 UI · 공방 · 통합 a/design-ui 의 조각)

디자이너 시안 `09-workshop`(강화 · 강화 장비 고르기 · 보석 고르기 · 제작 · 물약 · 14상태)을 `VillageWorkshopGroup` 에 입힌다. 1단계 = 겉모습. 서버 파일(`EnhanceService` · `CraftService` · `ShopService` · `RepairService`) · CSV · `InventoryUIController`(공용 툴팁) · `VillageNpcUIController` 는 건드리지 않았다. 고친 스크립트는 `Item/WorkshopUIController.mlua` 하나.
🔴 **Play 로 본 것은 없다**(Maker 미사용) — 위치 · 그리기 순서 · 글자 폭은 통합 담당이 눈으로 확인해야 한다. (레이아웃은 시안 실측 좌표를 그대로 써서 만든 모의 렌더로 s0 · s3 · s4 · s5 · s6 · s10 · s11 · s13 위치만 시안과 대조했다 — 그림 · 글꼴 · 스크립트 동작은 못 봤다.)

## 안 한 것 (2단계 · 새 기능이거나 서버가 새 값을 줘야 하거나 에셋이 없음)

- **보석 자동 채우기**(시안 #36 · "제안") — 새 기능이고 우선순위 규칙(가장 많이 가진 것 / 능력치 순)이 기획 결정이라 자리(`GemBar/AutoFill` 버튼 · 꺼 둠)만 만들었다. 클릭을 연결하지 않았다.
- **성공 시 0.4초 반짝임**(시안 "제안") · **진행 중 돌아가는 원** — 애니메이션은 안 했다. 진행 중은 회색 "강화 중..." 글자만.
- **제작 목록 스크롤바 그림**(시안 #27) — GridView 스크롤 위치를 읽는 API 를 확인 못 했다. GridView 자체 스크롤 막대(손잡이만 금색)를 그대로 둔다.
- **교환 카드 보라 안쪽 테**(시안 #38) — 전용 에셋 없음(교환 배지만). **HP · MP 능력치 아이콘** — 에셋 없음(줄 아이콘이 빈 자리로 남는다). **부족 표시 빨간 테** — 전용 에셋 없음 → `plate_dark` 를 붉은 색으로 곱해 대체.
- **그라데이션**(화면 막 · 바닥 띠 배경 · 제목 양옆 선 끝 · 능력치 줄 이름표 띠) · **그림자**(창 · 문장) · **점선 자리**(결과 줄 · 능력치 판) — 생략하거나 단색으로.
- **한 글자줄 안 글꼴 섞기**(이름 Maple + 단계 Football · 숫자 Football 18 + 14) — 못 해서 한 글꼴로 통일하고 색 태그만 쓴다.
- **칩 폭이 내용에 맞춰 변하는 것**(시안) — 글자 폭을 재는 API 가 없어 글자 **수**로 어림한다(한글 0.93em · 숫자 0.6em · 쉼표 0.3em). 어림이라 글자 사이 간격이 ±2px 흔들린다.
- 수리 화면 · 지역 장비 상인(비활성 NPC) 제목 아이콘 — 시안 없음(아이콘 끔).
- B 코드(`Skill/**` · `Job/**` · `PlayerAttack.mlua`) — 건드릴 것 없음.

## 단순화한 것 (시안과 다른 곳)

- **제작 카드 높이 128 → 118**: 부위 분류 7칸(시안에 없음)을 넣을 자리가 없어 직업 칩 줄 아래에 26 높이 줄을 끼우고 목록 판을 그만큼(268 → 296) 낮췄다. 카드 3줄이 한 번에 보이는 시안 의도는 지킨다. 카드 안 간격도 그만큼 조였다(값 줄 아래 여백 7).
- 부위 분류는 마을 장비 상인에서만 보인다(예전과 같다) — 리스항구 초보자 장비(분류 없음)는 위쪽이 비고 카드가 아래로 더 낮은 채 나온다(시안에 이 모양이 없다 · 비활성 NPC 라 보이지 않을 가능성이 크다).
- 능력치 줄 수: 시안은 줄 높이 46 이라 강화 판(212)엔 2줄, 제작 상세엔 3줄(재료 2줄일 때 · 재료가 1줄이면 5줄)까지 들어간다. 넘으면 줄을 작게(강화 26 · 제작 30) · 글자 14 로 줄인다. 그래서 최대 4줄(강화) · 5줄(제작)을 예전처럼 다 보여 준다.
- 제작 상세 머리(큰 그림 · 이름 · 직업 칩 줄)는 이름 두 줄을 항상 자리로 잡고 아래 정렬한다(한 줄 이름은 시안보다 조금 아래).
- 강화 보석 칸 "필요 없음" 글자 위치 · 안내 제목 줄(처음 화면에서 시안은 12.5px 내려옴)은 고정 자리.
- 결과 문구 양옆 반짝이 · 경고는 글자 폭 222 기준 고정 자리(±132) — 문구가 길면 글자와 겹칠 수 있다.
- 제목 NPC 이름은 4글자 기준으로 아이콘 오른쪽에 두 칸(+22) 치우친 자리(긴 이름은 아이콘 쪽으로 겹칠 수 있다).
- 강화 보석 칩의 "보유" = 지금 넣은 보석 수(시안 s5 · s7 에서 읽음). 메소 칩이 모자라면 붉게 보이지만 **버튼은 메소로 막지 않는다**(서버가 거절 · 예전 동작 그대로 · 재현 레시피 D02 가 이 경로를 쓴다).
- 강화 "화살표" 회색 = 색 곱 0.6 + 불투명 0.45(회색조 필터 대신).
- 보석 고르기 "보유 0" 그림은 색 곱 0.6(회색조 필터 대신) · "효과 없음" 0.35.
- 한 에셋의 테두리 두께는 한 값이라: `slot_frame_disabled`(15) 는 보석 고르기 147×176 에서도 15(시안 20) · 직업 태그 칩은 세로 22(`chip_*` 테두리 11 × 2 때문에 시안 19 → 22) · 해적 태그는 `chip_blue_dark_sm` · 교환 배지 · MAX 칩 · 착용 표식은 `chip_gold` · `chip_blue` 한 두께.
- 화면 막: 방사형 그라데이션 → `#060A14` 알파 0.6 단색.

## 확인 전

- Play / Maker 로 본 것은 **없다.** `ui_lint` 에러 0(경고 56 = 작은 버튼 터치 크기 28 · 켜고 끄는 겹침 · 상태별 배지 줄 정렬 — 기존 것 + 겹쳐 깐 그림), 스크립트 LSP 이슈 0, `check-integrity` 통과. 적용 스크립트는 두 번 돌려도 같은 파일(바이트 동일).
- 눈으로 봐야 할 것: ① 제목 띠 위 글자 · 아이콘 자리 · 문장과 띠가 겹치는 순서 ② 칩 안 글자 자리(어림) · 카드 값 줄 묶음이 가운데인지 ③ 칸 상태 겹침(빈 칸 틀 · 회색 틀 · 최대 단계 덮개)이 그림이 제대로 덮는지 — 특히 눌러야 하는 칸(강화 대상 칸 · 보석 칸)은 받침(`slot_frame`)을 알파 0.01 로 숨기고 겹쳐 깐 그림을 켜는데 이게 클릭(레이캐스트)을 막지 않는지 ④ 능력치 줄 크기 전환(3줄 이상) ⑤ 재료 줄이 줄 수에 따라 아래에서 쌓이는지 · 제목이 내려오는지 ⑥ 강화 고르기 칸 이름이 칸 아래에 그려지는지(GridView 간격 40) ⑦ 제작 카드 · 물약 카드 GridView 칸 크기(174×118 · 180×150 · 간격 10)를 컴포넌트 값으로 잡았다 — 템플릿 크기와 같이 맞는지 ⑧ 기본 스크롤 막대 모양.
- 요청 사진 레시피(`디자인인계/2026-09-23/_work/recipes/workshop.json` D01 ~ D16)의 Lua 는 **고친 뒤에도 그대로 돈다**(쓰는 메서드 · property · 자식 이름이 모두 있다). 다만 예전 글자에 기대는 로그는 값이 바뀐다: `targetText` · `resultText` 는 이제 "장비 선택" / "강화 후"(이름은 새 라벨 `TargetName` · `ResultName`) · `costLabel` 은 칩 모드에서 숨은 채 글만 남음 · `craftDetail/Req` 는 빈 글.
