# a/design-ui-trial (임시 · 디자이너 시안 시험 · Draft PR #99 · 머지 안 할 수 있음)

디자이너가 준 매치 로비 시안(`메월드폴더/리소스파일/매치로비ui`)을 게임에 입혀 본다. 그림 16장은 계정 리소스로 올렸고,
시안에 구워진 글자는 지우고 게임 글꼴(`Default`) 텍스트로 덮었다. 방 대기 화면(RoomHud)은 따로 받기로 해서 그대로 둔다.

| 항목 | 내용 | 파일 |
|---|---|---|
| 로비 배치 | 창을 시안 배치대로 1920×1080 전체로 옮김 · 배경/틀 그림 · 왼쪽 "대기 중인 매치"(사람 아이콘 · 빈 상태 그림·구분선·안내 · 매치 줄 6칸 = `lobby_match_row` 9-slice) · 오른쪽 "난이도"(탭 판 · ★1/★3/★5 탭 · 카드 판 · 엠블럼 · 카드 제목/심장/소개/목록 · 나머지 난이도 두 줄 · 상태 바) · 아래 비용 안내 + "매치 만들기" 버튼(칼 아이콘) · 노드는 지우지 않고 위치·그림·글자만 바꿈 + 아이콘·카드 글자 칸 추가 | `ui/LobbyGroup` |
| 월드맵 버튼 | `Toolbar/OpenBtn` 그림·글자만 교체 (위치·크기 그대로) | `ui/WorldMapGroup` |
| 컨트롤러 | 탭 모드(`UseTabs`): ★ 탭 켜짐/꺼짐 그림 교체 · 고른 난이도 줄은 숨기고 나머지를 위부터 채움 · 카드(제목·심장·소개·금색 ◆ 목록) · 추천 ★ 자동 선택(`AutoPickRecommended`) · 매치 줄 선택 색 · 줄 라벨 ★/★★/★★★ · 잠김 안내를 한 줄로 · 탭 UI 가 없으면 예전 동작 그대로 | `Match/LobbyUIController.mlua` |
