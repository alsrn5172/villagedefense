# a/miss-color-monster — MISS·관문·발록·전직 UI/안내 (Draft PR #193)

## 2026-10-06

사용자 지시: "몬스터한테서 뜨는 miss 가 보라색으로 뜸. 보라색 miss 는 플레이어가 뜨는 색깔이고 몬스터는 빨간색으로 떠야함"

- `Stat/DamageFormula.mlua` `ShowMiss` — 대상에 따라 스킨을 고른다. 대상이 플레이어(`PlayerComponent` 있음)면 지금 그대로 `MissSkinId`(`02c22d93…` · 몬스터 공격 스킨 · 보라), 그 외(몬스터 · 수비대 · 미니언)는 새 속성 `MissSkinMonsterId`(기본 `3271c3e7…` = `DefaultPlayer` 의 플레이어 기본 데미지 스킨 · 빨강 계열).
- 전에는 대상이 누구든 `MissSkinId` 하나를 써서 플레이어 공격이 빗나갔을 때 몬스터 머리 위 MISS 도 보라였다. 호출하는 쪽(`StatService` 기본 공격 · `SkillDatabase` 스킬 · `MonsterAttack` · `FactionAttack` 회피)은 안 바꿨다.

## 확인

- [x] mLua 진단 이슈 0.
- [x] Maker Play: `ShowMiss`를 실제 달팽이와 플레이어에 호출해 몬스터 빨강·플레이어 보라를 캡처로 확인. 이전 빨강 추정은 실측으로 확인됨.

## 추가 요청 반영 (2026-10-06)

- 차원 관문: 지역재화와 에너지 코어를 모두 확인하고 목적지까지 검증한 다음 차감·이동한다. 지역재화 부족 시 코어를 소모하지 않는다. UI도 재화 부족 시 이동 버튼을 잠근다. 성공 시 두 비용을 한 번 차감하고 보스방으로 이동하며 창을 닫는다.
- 발록(8130100): HP 38,000 → 45,600, 공격력 210 → 252(각각 +20%). 다른 능력치는 유지.
- 꿈의 조각: 보스 추가 보상과 엘리트 처치 보상을 각각 60% 확률로 변경. 드롭 수량·수량 배율과 다른 보상은 유지.
- 차원의 거울: 순간이동 라벨을 제목과 같은 글꼴·크기·스타일로 표시하고 칩의 가로·세로 중앙에 정렬. 제목도 좌우 장식(-100,+100)의 정확한 중점(0)에 배치.
- 전직 NPC: 기존 패널·초상·금색 버튼 리소스를 UIBuilder로 재사용. 기존 UUID/클릭 바인딩 유지. 전직 후 안내 문구는 오른쪽 본문 아래로 정렬.
- 첫 전직 안내: PlayerSkillState가 발행하는 JobChangedEvent를 구독해 확정된 NOVICE → 1차 전직에만 안내. 실제 거울에 금테·고리·화살표 표시(화면 밖이면 방향 안내), 화면을 어둡게 덮지 않음. 거울 UI를 열거나 맵을 떠나면 종료. 월드맵의 빈 마을 목표도 표시.
- B 담당 Skill/Job 스크립트는 수정하지 않음. 요청과 무관한 기존 Maker 변경(다른 UI 및 맵)은 보존하고 이 PR 추가 커밋에서 제외.
