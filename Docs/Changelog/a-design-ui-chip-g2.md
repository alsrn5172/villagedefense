# a/design-ui-chip-g2 (디자이너 시안 갱신 · 칩 글자 대비 · 2단계 G2 = 캐릭터 · 공방 · 스킬 · 계정)

기반 = `a/design-ui-chip-contrast`(1단계 · `S.chipText` + `_UiChipText`). 규칙 · 대응 표 = `디자인인계/디자이너-시안-2026-10-01/spec/_plan/_chip-contrast.md`.
밝은 칩(`chip_gold` · `chip_gray`) 위 글자 = `#1C1405` + 외곽선 없음 + 밝은 그림자, 보석 칩(`chip_green` · `chip_blue` · `chip_red`) 위 글자 = 흰색 + 외곽선 `#050A16` + 어두운 그림자. 칩 그림 3장은 같은 RUID 로 이미 교체돼 있어 `.ui` 의 RUID 는 그대로다.
확인 전(Maker 로 눈으로 본 것 없음) — 아래 "검증 때 볼 것" 참고.

## 한 것

| 창 | 파일(`.ui`) 쪽 | 고친 칩 글자 엔티티 |
|---|---|---|
| 캐릭터(`CharacterGroup`) | 기본 상태에서 고른 분류 "전체"(금 칩) 글자 · 좌우 여백 11 | 1 |
| 공방(`VillageWorkshopGroup`) | 착용(범례 · 고르기 칸 · 파랑) · MAX 2곳 · 교환 배지(금). 교환 글자색 `#1B1030` → `#1C1405` | 5 |
| 스킬(`SkillWindow`) | 액티브(파랑) · 패시브(초록) 칩 + 툴팁 칩 2개. 칩 폭 60.5 → 62.5 · 툴팁 칩 84 → 86 | 4 |
| 계정(`AccountRecordGroup`) | 달성 · 발록 처치(금) · 시간 종료(회색 · `#2A3040` → `#1C1405`) · 전원 탈락(빨강) | 4 |

- 각 `apply-<창>.cjs` 맨 끝에 칩 글자 규칙 호출을 넣었다. 두 번 돌려 `.ui` 가 바이트까지 같음 · `ui_lint` 에러 0.
- **새 파일 `Docs/tools/design-ui/chiptext-keeprect.cjs`**: 공용 `S.chipText` 는 칩 안 글자 상자를 `칩 폭 - 2 x (테두리 + 1)` 로 줄이는데(교환 배지 44 → 22 · 액티브 62.5 → 38.5), 시안 칩 폭은 시안 글꼴 기준이고 게임 글꼴은 10~15% 넓어 줄이면 글자가 꺾이거나 잘린다. 글자는 가운데 정렬이라 상자를 칩 폭 그대로 두어도 좌우 여백은 같으므로, 호출 뒤 상자 크기만 원래대로 되돌리는 감싸개를 4개 apply 가 쓴다. **`skin.cjs` 는 고치지 않았다(공용 수정 필요 — 보고 참고).**
- 글자가 칩의 형제인 곳(제작 탭 `Job_x` · `Slot_x` 의 `On` + `Label` · 직업 칩 `JobChip/Bg_x` + `Job` · 요구 칩 `ReqChip/Bg_x` + `Label`)은 기본 상태가 "꺼짐(어두운 칩 + 밝은 글자)"이라 파일에 규칙을 박으면 꺼진 상태가 틀려진다 → 켤 때 컨트롤러가 건다(아래).

## 검증 때 볼 것 (상태 이름 = 시안 상태 번호 · 요청 사진 이름은 캡처 쪽 표를 따른다)

- 캐릭터 가방 분류(시안 07-char s2~s9): "전체"가 금 칩 + 어두운 글자 · 다른 분류를 누르면 그 분류가 금 칩 + 어두운 글자로 바뀌고 이전 분류는 짙은 파랑 칩 + 밝은 글자(외곽선 · 그림자 없음)로 돌아오는지.
- 공방 제작(09-workshop s8~s11): 고른 직업 탭(전사/궁수…) 글자가 잉크색인지 · 안 고른 탭은 밝은 글자인지. 카드 직업 칩 "전사"(빨강) · "궁수"(초록)가 흰 글자 + 짙은 외곽선으로 또렷한지 · 도적/해적/전직업(어두운 칩)은 그냥 흰 글자인지. 교환 배지 "교환"이 잉크색 · 줄이 안 꺾이는지(상자 44).
- 공방 강화(s1 착용 · s6 MAX): 착용(파랑) 흰 글자 + 외곽선 · MAX 잉크색.
- 스킬 창(08-skill s0 · s1 · s3~s7): 액티브(파랑) · 패시브(초록) 칩 글자가 흰색 + 외곽선 · 칩 안 글자가 꺾이지 않는지 · 툴팁(s5 "액티브 · Q" · s6 "액티브 · Shift") 칩이 글자 + 24 폭인지.
- 계정 기록(03-account s2 달성/받음 · s4 시간 종료 · 전원 탈락): 회색 칩 위 "시간 종료"가 잉크색(이전 `#2A3040` 아님) · 빨강 칩 위 "전원 탈락"이 흰색 + 외곽선.
- 모든 외곽선 굵기: `CHIP_OUTLINE_WIDTH = 0.25`(추정). 두껍거나 얇으면 `skin.cjs` · `Match/UiChipText.mlua` 두 곳을 같은 값으로 조정(공용 · 1단계 담당). 잉크 글자의 밝은 그림자(흰색 45%)가 거슬리지 않는지도 같이.

## 못 한 것 · 메모

- 계정 도감(03-account s0 · s1) "보스" 칩(빨강 48×25): 게임 `AccountRecordUIController` 에 도감 구분 "보스" 칩이 없다(보스는 `Lv N 보스` 글자로만 표시) → 대응 엔티티 없음 · 건드리지 않음.
- 공방 "요구 레벨 칩"(`Detail/ReqChip`)은 시안 63×19 · 게임 54×22(원래부터 다른 값 · 시안 칩 크기는 이번에 안 바뀜) → 크기 그대로, 글자 규칙만 런타임에서 건다.
- 눈으로 본 확인은 안 했다(Maker 미사용).
