## 튜토리얼
- **C 를 눌러 물약 등록하는 장면에서 캐릭터 창이 열렸다 바로 닫힘**: 진행기의 "허락 안 한 창 닫기"(`TutorialDirector.CloseOthers`)가 NPC 창 전부 닫기(`VillageNpcUIController.CloseAll("")`)를 불렀는데 그 안에 캐릭터 창도 들어 있었다(로그 스택으로 확인). 캐릭터 창을 쓰는 장면(물약 등록 · 장비 입기)에선 `CloseAll("CharacterGroup")` 로 남긴다.
- **C 버튼 강조가 두 칸 왼쪽 빈 자리에 뜸**: 강조 위치 계산(`CoachMarkController.RectOfUI`)이 쓰던 `GetWorldCorners` 가 게임 화면 크기가 바뀐 뒤 그룹마다 갱신이 엇갈렸다(StatusHUD 는 옛 크기 그대로 · 실측). 앵커 · 오프셋 · 크기로 직접 계산(`LayoutRect`)하고, 그리드 칸은 칸 번호 · 칸 크기 · 간격 · 여백 · 스크롤로 계산(`GridCellRect`)한다. 로비 안내(장비 · AP)의 같은 버튼 강조도 함께 고쳐진다.
- **물약 등록 순서**: C 로 창 열기 → **장비 · 인벤토리 탭 누르기(새 장면 1-0pt · 탭 강조)** → **가방 속 빨간 포션 칸만 강조 · 설명은 위**(1-0pb) → 1번 칸에 놓기. 가방 칸 번호 = `InventoryUIController.IndexOfItem`. 장비 입기(4-2f)도 같은 방식으로 새 무기 칸을 가리키고 탭을 장비 · 인벤토리로 맞춘다.
- **설명 카드 칩**(게임 소개 · 레벨 업 …): 박스는 그대로 두고 창 위쪽 가운데로 옮겨 크게(260x46 · 글자 24).
