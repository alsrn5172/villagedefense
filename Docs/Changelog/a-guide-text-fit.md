# a/guide-text-fit — 모바일 안내 UI 글이 안 보임 · 체크리스트 제목 꺾임 (Draft PR #188)

## 2026-10-06

- `ui/GuideGroup` 글 칸 2개에 **글자 자동 축소**(`BestFit=true` · `MinSize` · `MaxSize` · `Overflow=0`):
  - `Bar/GoalText`(안내 띠 목표 문장): 글자 12~20.
  - `CheckPanel/Title`("초보자 체크리스트"): 글자 14~24.
  - 상자 크기 · 위치 · 색은 그대로. 최대 크기가 원래 `FontSize` 라 짧은 글은 예전과 똑같이 보이고, 긴 글만 줄어든다.
- 전후 비교(빌더로 79개 엔티티 전부): 달라진 값은 위 두 칸의 7개뿐.
- 원인: `GoalText` 는 `Overflow=Truncate` 에 상자 높이가 한 줄(28)이라, 20px 로 840px 를 넘는 목표 문장(G13 46자 · G10 44자 · G8 42자 · G14 …)은 둘째 줄로 꺾이면서 글이 지워진다. `Title` 은 190px 에 24px 8글자(약 192px)라 처음부터 아슬아슬했다.

## 확인

- [ ] Maker Play(PC): 46자 목표 문장을 직접 넣어 한 줄로 줄어 보인다.
- [ ] 사람 눈(모바일): 안내 띠에 목표 문장이 보이고 체크리스트 제목이 한 줄이다.
- 같은 방식으로 좁은 칸에 긴 글이 들어가는 다른 모바일 UI(알림 카드 · 안내 말풍선 등)는 이번에 안 봤다.
