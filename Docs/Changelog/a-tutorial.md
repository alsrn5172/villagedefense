## 튜토리얼
- **1인 휘발성 룸**: 소개 8쪽 [튜토리얼 시작하기] · 도움말 [튜토리얼] → `TutorialService.RequestStart` 가 매치와 같은 인스턴스 룸 `tutorial_<세대>` 를 만들어 혼자 보낸다(Maker 는 지금 방에서 `InPlace`). 룸 안 매치 엔진은 그대로 돌고 시계 · 웨이브 표 · 미점령 탈락 · 결과 · 정산 · 저장은 끈다(`MatchSessionLogic.IsTutorial` · `EndQuiet`). 업적 · 계정 도감 · 플레이 기록도 안 쌓인다.
- **진행자** `TutorialDirector`(클라 · 장면 107개 · 6단계): 1 전직 · 마을 차지 → 2 월드맵 · 사냥 → 3 미니언 방어(포탑 · 억제기 · 넥서스 · 도감 해금 · 수비대 모집 · 포탑 강화 · 웨이브 · Lv20 2차 전직) → 4 보스 준비(제작 · 착용 · 물약 · 강화) → 5 마을 보스(머쉬맘 · 단풍 봉인석 · 앱솔랩스 교환 · 영혼석) → 6 견제 · 발록(Lv30 3차 · 먼저 발록에 가는 상대 · 견제 규칙 · 파병 · 발록 안내) → 완료 → 로비 · 도움말 1쪽.
- **강조 화면**: `CoachMarkController.ShowCustom/HideCustom`(막 · 구멍 · 말풍선 재사용 · 대상 = UI 경로 · UI 엔티티 · 월드 엔티티 상자 · 사각형). 새 `TutorialGroup`(페이드 · 단계 칩 · 큰 설명창 · 넥서스 체력 바 · [그만두기] + 확인창).
- **입력 = 의도한 하나만**: 이동 · 점프 · 공격 = `AddCondition` · UI 단축키 = 키 처리 파일 9곳 맨 앞 `TutorialDirector:KeyAllowed` · 클릭 = 막 · 허락 안 한 창은 바로 닫음.
- **서버 장면 일**: 달팽이 · 주황버섯 스폰 · 레벨(정식 경로) · 연출용 재화 · 순간이동(NPC · 시설 · 사냥터) · 웨이브 1회 · 보스 약화 · 파병 가상 상대(엘리니아 · 튜토리얼에서만 주인 있는 마을로 보임 · 파병 규칙 1페이즈 값).
- 튜토리얼 외형 = 전직 외형 OFF(내 아바타는 모험가로) · 무적.
- **첫 사냥 직전 물약 퀵슬롯 등록**(1-0p): 빨간 포션 5개 지급 → 캐릭터 창(C) → 가방의 포션을 왼쪽 아래 1번 칸에 끌어다 놓기(이 장면만 막 없이) → 숫자 키 1 안내. 4-3d 문구도 "아까 등록한 칸"으로.
- **월드맵 목표 핀 = 지금 할 일의 맵**: 장면 `pin`(사냥터 → 리스항구 → 헤네시스 → 사냥터 1 → 사냥터 2 → 마을 → 보스 맵 → 없음) · 시작/끝에 지움.
