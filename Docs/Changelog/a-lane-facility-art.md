### 쓴 방법 · 주의 (M2 가 같이 쓰도록)

- 옛 ↔ 새 비교: 클라 `execute_script` 에서 전역 함수를 정의해 둔다 — 한 마을만 남기고 나머지 시설 스프라이트 알파 0 · "옛" 이면 `LaneFacilityArt.Enable=false` + 옛 RUID + `Scale 0.25` + `WorldPosition.y = 슬롯 y + 옛 Ground`. 테스트맵 줄 간격(2.925)이 새 그림 높이(3.3+)보다 좁아 줄끼리 겹치므로 **마을별로 나눠 찍는다**.
- 손상 · 완파 화면: 서버 `TestSetFacilityHpPct` / `TestDestroyFacility` 로 상태를 바꾼 뒤 **2초 기다렸다가** 알파 0 으로 가리는 함수를 다시 부른다(상태 바뀔 때 서버가 색을 다시 칠한다).
- 공격 프레임을 멈춰 찍기: 클라 `LaneFacilityArt.HoldIndex = N`(그 상태 `Frames` 의 N번째). 🔴 이미 멈춘 채로 `Tier` 가 바뀌면 다시 안 칠한다 → `HoldIndex = 0` 으로 풀고 0.6초 뒤 다시 건다.
- 플레이어는 시설의 적이다 — 시설 가까이 서면 포탑이 플레이어를 쏜다(한 번에 약 7800). 캡처 때는 서버에서 `TurretAI.Enable = false` 를 걸고, `ApplyCombat` 이 상태 변경 때 다시 켜므로 상태를 바꾼 뒤 다시 끈다.
- 확대: 클라 `_CameraService:ZoomTo(120)` + `CameraComponent.CameraOffset` 로 한 시설을 가운데로. 스크린샷은 1093×615 · 줌 60 에서 약 51px/유닛 · 줌 100 에서 85px/유닛.
- 엔티티 이름에 `:` 를 넣으면 `LEA-3021`(마커로 쓴 임시 엔티티 이름) · 임시 마커는 `lanehpbar` 모델이 너무 커서 안 맞았다 → 발사점은 `WorldToScreenPosition` 으로 화면 좌표를 구해 캡처 위에 겹쳤다.

### 사용자에게 물을 것

1. **커닝 포탑 크기**: 옛 그림(`KerningCity_Tower` · `GroundOffset` 1.125 미조정)이 바닥에 **0.57유닛 묻혀** 있어 보이던 높이는 2.81 이었다. 새 그림은 묻히지 않게 앉히고 높이는 옛 그림 **전체 높이 3.38**(= 다른 시설과 같은 비율 · Scale 0.509)에 맞췄다 → 보이던 높이보다 **약 20% 큼**. 보이던 높이(2.81)에 맞추면 Scale 0.42(억제기 · 넥서스보다 작아 보임).
2. (참고) 헤네시스 포탑은 새 그림이 옛 그림보다 3% 작다(Scale 0.47 → 0.485 로 올리면 같음) — 조각 0 에서 눈으로 맞춘 값이라 그대로 뒀다.
