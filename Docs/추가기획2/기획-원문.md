### 침범 허용 행위와 저항,보상,안정 장치

타 플레이어가 포탑,억제기, 넥서스 공격 가능
포탑이 살아있으면 억제기는 무적, 억제기 살아있으면 넥서스 무적
포탑은 파괴만 알림이 뜨며
억제기와 넥서스는 공격받기만 해도 알림이 뜸.

수비대 몬스터들은 이동속도가 기본적으로 일반 몬스터의 2배이기때문에 근접공격이더라도 포탑없이 상대플레이어 상대로 방어 가능.

수비대 몬스터들은 포탑 사정거리의 80%이내로만 움직이고 억제기, 넥서스에도 공격 기능이 없어도 같은 범위 알고리즘을 가짐.

### 마을별 넥서스, 억제기, 포탑의 특성

### 포탑 억제기 넥서스의 1~3레벨 밸런스, 공격 방식, 플레이어가 미치는 영향에 대한 설정

1~2페이즈때는 5%만, 3페이즈때부턴 공격가능, 수비대 몬스터와 포탑은 플레이어 상대로는 (계수-기본10)배 공격

포탑 공격 방식 : 기존 - 원거리 범위내의 적 전부 공격

변경 - 억제기도 범위효과가 있음

1. 헤네시스 :

    헤네시스 포탑은 기본 효과임

    억제기도 공격을 함. 포탑 공격과 데미지테이블의 2배임. 대신 3마리만 공격임. 그럼 이제 제 2차 포탑 느낌이라 첫 포탑을 깔끔하게 포기해도 됨

2. 커닝시티 :

    커닝시티는 사냥터 2에 포탑이 있고 뒤에 억제기가 바로 있음. 포탑이 원거리 단일 공격을 매우 강하게 함

    1. 기존 데미지의 5배 정도면 될 듯

    억제기는 범위 내 아군들(플레이어, 수비대)의 이동속도를 증가시킴(Lv1 : 10%, Lv2 : 20%, Lv3 : 30%)

3. 페리온 :

    포탑 : 기본 효과

    억제기 : 공격 받을 시 반사함. 받은 피해의 10배만큼 반사. 플레이어 상대로도 10배 반사임.

4. 엘리니아 :

    포탑 : 마법을 쓰며 공격함(기본 효과)

    억제기 : 주변 아군에게 버프를 줌(공격력 버프)

5. 노틸러스 호 :

    포탑 : 단일 공격 후 주변으로 퍼져서 터짐 (단일은 2배로 들어가고 주변 범위는 데미지 그대로)

    억제기 : 주변 아군에게 버프를 줌(자동 체력회복- 억제기 본인도)

경험치는 기존처럼 플레이어가 막타쳐야만 주는 것 유지

### 결과 화면, 관전, 순위별 발록의 심장 수량, 플레이 기록

결과 화면 = 플레이 기록

(가한 데미지가 제일 먼저 판단되고, 넥서스hp,레벨,몬스터 처치수가 우선순위가 낮은순서)
 (데미지0, HP 풀피, 레벨 동일은 가능해도 몬스터 처치 수까지 같을 수 없다고 판단, 거기까지 같으면 이름순으로 처리)
