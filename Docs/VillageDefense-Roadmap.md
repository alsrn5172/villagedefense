## 제품 비전

1레벨로 시작해 **10레벨 전직과 함께 마을 하나를 차지하고, 무너지지 않으면서 슬리피우드의 주니어 발록을 가장 먼저 잡는 사람이 이긴다.** 마을로 향하는 사냥터 레인 아래를 미니언이 끝없이 걸어오고, **그 사냥터가 곧 내 성장터이자 방어선**이다.

한 문장으로: **내 사냥터가 곧 내 방어선이고, 방어에 쓴 시간은 발록까지의 거리다.**

## 전체 출시 기준

- 2~6명이 한 Room에서 마을을 선점하고 **20~25분 안에** 승자가 나온다.
- 1레벨 → 10레벨 전직 → 코어 연결이라는 개척 구간이 매치 도입부로 성립한다.
- 4단 방어선(1차포탑 → 2차포탑 → 억제기 → 코어)이 순서대로 밀리며 패배가 결정된다.
- 사냥·엘리트·보스·미니언이 하나의 성장 경제로 연결된다.
- 미니언이 4페이즈에 걸쳐 강해지고, 25분경이면 어떤 방어선도 무너진다.
- 주니어 발록 선취가 실제로 매치를 끝낸다.
- 마을 소유권과 21레벨 침범 게이트가 서버에서 강제된다.
- 매치 데이터는 완전히 초기화되고 영구 계정 데이터만 보존된다.
- 다인 동시 플레이, 이탈, 재접속, Room 격리에서 치명적인 상태 누수가 없다.


## 게임 전체 기능 지도

> "이 게임에 무엇이 들어가는가"를 기능 단위로 전부 나열하고, 각 기능이 어느 마일스톤에 속하는지 표시한다. **M1 항목의 세부 사양은 GDD에 있고, M2 이후 항목은 아직 한 줄짜리 의도다.**

## 마일스톤

### M1 — 한 판이 시작부터 승패까지 끝까지 굴러가는 기반

**상태:** ⬜ 게임 규칙 기준본 / 구현 전 / CoreVersion 통합 게이트 전
**상세:** [`VillageDefense-M1-GDD.md`](VillageDefense-M1-GDD.md)

범위: 위 기능 지도에서 **M1** 로 표시된 전부.

> ⚠️ **착수 전에 위 「미정 항목」의 #1~#5를 먼저 결정해야 한다.** 특히 **#1(개인 채널)은 승리 조건 전체가 걸려 있어** 불가능으로 판명되면 M1 범위를 다시 짜야 한다.

출구 조건:

- M1 GDD §7의 모든 Phase가 Maker 런타임 검증까지 `✅`다.
- 서로 다른 두 원본 월드의 CoreVersion·맵·스크립트·저장 호환성 게이트가 통과됐다.
- 2인 이상의 매치가 **20~25분 안에 승자가 나올 때까지** 끝나고, 매치 상태 누수와 영구 데이터 유실이 없다.
- 개척(1레벨→10레벨 전직→코어 연결)부터 4단 방어선 붕괴와 발록 선취까지 한 사이클이 실제로 굴러간다.
- 포탑 파괴·전선 이동·발록 선취 이벤트가 한 번만 반영된다.

### M2 — 결과 화면과 승리 루프 확장

**상태:** 후보 / M1 완료 후 범위 확정

- 중도 이탈의 경쟁 패널티·재매칭 정책
- 발록 외 추가 승리 경로를 넣을지 여기서 판단

### M3 — 콘텐츠 확장과 경쟁 밸런스

- 마을 테마별 고유 시설
- 파병 편성 심화(진형·타이밍)
- 관전·리플레이
- 데이터 기반 경제·훈련·시설 밸런스 조정

### M4 — 라이브 운영

**상태:** 장기 후보

## 변경 규칙

1. 현재 마일스톤의 범위 변경은 해당 GDD §10에 이유와 날짜를 기록한다.

3. 구현 승인이 나면 별도의 `M2-GDD`, `M3-GDD`로 승격한다.
4. 런타임 검증 전에는 작업 체크를 `✅`로 바꾸지 않는다.
5. 두 원본 월드에 기능을 중복 구현하지 않고, 맵·데이터를 합친 하나의 통합 대상에서만 완성한다.
